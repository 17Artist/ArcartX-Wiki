Rondo 的每种货币都对应 `plugins/Rondo/currencies/` 下的一个 YAML 文件。文件名、配置中的 `id`、命令参数与 API 参数使用同一个标识。

## 完整结构

```yaml
# 唯一标识，必须与文件名一致
id: my_currency

display-name: "我的货币"
symbol: "◆"
color: "GOLD"
description: "这是一种自定义货币"

# 精度与余额边界
decimal-places: 0
max-balance: -1
default-balance: 0
negative-allowed: false

# 行为
tradeable: true
transferable: true
transfer-tax-rate: 0.05

# 集成
vault-primary: false
ranking-enabled: true
```

<Callout type="info">
`tradeable` 目前只供第三方插件读取；是否允许玩家转账由 `transferable` 决定。
</Callout>

---

## 字段说明

| 字段                  | 说明                                 |
|---------------------|------------------------------------|
| `id`                | 货币 ID，必须与文件名一致，只能使用小写字母、数字、下划线和连字符 |
| `display-name`      | 显示名称                               |
| `symbol`            | 货币符号                               |
| `color`             | Minecraft 颜色名或 `§` 颜色代码            |
| `decimal-places`    | 小数位数，范围 `0..4`                     |
| `max-balance`       | 余额上限，`-1` 表示不限制                    |
| `default-balance`   | 新玩家初始余额                            |
| `negative-allowed`  | 是否允许负余额                            |
| `transferable`      | 是否允许 `/money pay` 与 API 转账         |
| `transfer-tax-rate` | 转账税率，`0.05` 表示额外扣除 5%              |
| `vault-primary`     | 是否作为 Vault 主货币，全局最多一个              |
| `ranking-enabled`   | 是否加入排行榜                            |

例如转账 100、税率为 5% 时，发送方扣除 105，接收方得到 100。

---

## 新增、修改与删除

1. 在 `currencies/` 中创建 `.yml` 文件。
2. 让文件名与 `id` 完全一致。
3. 执行 `/rondo reload`。

<Callout type="warn">
删除货币配置不会自动删除数据库中的余额和流水。
</Callout>
