# 玩家兑换

玩家只有一条命令：

```text
/cdk open
```

默认需要 `giftcode.use` 权限。

## 兑换流程

<Steps>

<Step>

### 打开界面

执行 `/cdk open`，在兑换框中输入管理员发放的礼包码。

</Step>

<Step>

### 提交兑换

点击“兑换”并等待服务端返回结果。常见的短横线、空格或下划线差异不会影响识别，字母大小写也不敏感。

</Step>

<Step>

### 打开奖励邮件

兑换成功后，前往 SystemMail 收件箱查看并领取奖励。邮件可能包含物品、货币或命令附件。

</Step>

</Steps>

## 常见结果

| 提示          | 含义                    |
|-------------|-----------------------|
| 奖励邮件已经送达    | 兑换与邮件投递均已完成           |
| 奖励邮件稍后送达    | 领取资格已经记录，后台会继续投递邮件    |
| 兑换码不存在或格式错误 | 输入内容不正确，或该兑换码不属于当前服务器 |
| 兑换码或礼包不可用   | 兑换码已停用，或礼包被管理员关闭      |
| 兑换码已经过期     | 当前兑换码已超过有效期           |
| 已经领取过       | 共享码对当前玩家只能使用一次        |
| 已经被领取       | 单次码已由其他玩家使用           |
| 达到总领取上限     | 共享码的全服领取次数已经用完        |


## 无法打开界面

先确认：

- 玩家拥有 `giftcode.use`；
- ArcartX、SystemMail 与 GiftCode 均已启用；
- 客户端资源中存在 `data/resource/gift_code/`；
- 服务端存在 `plugins/GiftCode/ui/redeem.yml`。
