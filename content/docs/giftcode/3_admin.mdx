# 礼包与兑换码

管理主命令为 `/giftcodeadmin`，简写为 `/gca`。直接执行主命令会显示帮助，使用 `/gca gui` 打开礼包编辑器。

## 权限

| 权限                        | 用途           |
|---------------------------|--------------|
| `giftcode.admin.edit`     | 创建和编辑礼包      |
| `giftcode.admin.generate` | 生成、导出和停用兑换码  |
| `giftcode.admin.stats`    | 查看礼包统计与生成批次  |
| `giftcode.admin.retry`    | 查看并重试失败的奖励邮件 |
| `giftcode.admin.reload`   | 重载语言与玩家兑换界面  |

OP 拥有全部管理权限。

## 创建与编辑礼包

<Steps>

<Step>

### 创建礼包

```text
/gca create <礼包ID> <single|perplayer>
```

礼包 ID 最长 64 位，只能使用小写字母、数字、点、下划线和短横线，且必须以字母或数字开头。

</Step>

<Step>

### 打开编辑器

```text
/gca gui
```

选择礼包后，可以设置显示名、说明、启用状态、兑换模式、兑换码默认有效期、共享码总领取上限，以及奖励邮件内容。

</Step>

<Step>

### 保存修改

编辑完成后点击“保存修改”。直接关闭界面或选择“放弃本次未保存修改”都不会写入草稿内容。

</Step>

</Steps>

### 兑换模式

| 模式          | 适合场景         | 领取规则                       |
|-------------|--------------|----------------------------|
| `single`    | 一人一码         | 每个生成码全服只能成功使用一次            |
| `perplayer` | 节日码、公告码、全服福利 | 同一个共享码可由每名玩家使用一次，并可设置全服总上限 |

已经投放的礼包不建议修改兑换模式。需要更换领取规则时，创建新的礼包 ID 更容易核对数据。

## 奖励邮件

邮件的发件人、标题、正文和命令内容支持：

| 占位符        | 内容        |
|------------|-----------|
| `{player}` | 领取玩家名     |
| `{uuid}`   | 领取玩家 UUID |
| `{type}`   | 礼包显示名     |

### 物品附件

进入物品附件页后，点击玩家背包中的物品即可添加。单个礼包最多保存 27 个物品附件。

### 货币附件

```text
货币id|数量|显示名称|图标路径
```

后两项可以留空。例如：

```text
vault|1000|金币|
```

货币 ID 必须是当前服务器已经注册的可用服务，例如 ArcartX 的 Vault、PlayerPoints，或由 Rondo 注册的对应货币 ID。

单个礼包最多添加 16 个货币附件，同一种货币 ID 不能重复添加。

### 命令附件

```text
console|显示名称|图标路径|命令
player|显示名称|图标路径|命令
```

`console` 由控制台执行，`player` 以领取玩家身份执行。命令不要带开头斜杠：

```text
console|活动称号||lp user {player} permission set title.event true
```

单个礼包最多添加 16 个命令附件。命令是否能够执行，还会受到 SystemMail 的命令白名单限制。

## 生成与导出

```text
/gca generate <礼包ID> <数量> [有效期]
```

有效期支持 `30m`、`1h`、`7d`、纯秒数或 `permanent`，范围为 60 秒至 10 年。不填写时使用礼包中的默认有效期。

生成成功后，兑换码先保存在数据库，再导出到 `plugins/GiftCode/exports/`。

```text
/gca batches
/gca export <批次ID>
```

`batches` 显示最近十个生成批次；导出文件丢失或首次写出失败时，可以使用批次 ID 重新导出。

## 管理命令

| 命令                                     | 用途               |
|----------------------------------------|------------------|
| `/gca gui`                             | 打开礼包编辑器          |
| `/gca create <ID> <single\|perplayer>` | 创建礼包             |
| `/gca generate <ID> <数量> [有效期]`        | 生成兑换码并导出 TXT     |
| `/gca export <批次ID>`                   | 重新导出指定批次         |
| `/gca stats <礼包ID>`                    | 查看生成、领取、待发送和失败统计 |
| `/gca batches`                         | 查看最近十个生成批次       |
| `/gca failures`                        | 查看最近二十条发送失败记录    |
| `/gca disable <兑换码>`                   | 立即停用一个兑换码        |
| `/gca retry <领取记录ID>`                  | 重新发送失败的奖励邮件      |
| `/gca reload`                          | 重载语言与玩家兑换界面      |

<Callout type="info">
`/gca reload` 不会重载数据库、Redis、节点 ID、兑换码格式或后台任务参数；这些配置需要完整重启服务器。
</Callout>
