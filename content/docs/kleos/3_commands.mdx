# 命令与权限

| 命令                           | 权限                   | 说明                  |
|------------------------------|----------------------|---------------------|
| `/kleos open`                | `kleos.open`         | 打开称号界面              |
| `/kleos give <玩家> <称号> [时长]` | `kleos.admin.give`   | 向在线玩家授予或续期称号        |
| `/kleos remove <玩家> <称号>`    | `kleos.admin.remove` | 撤销在线玩家的指定称号         |
| `/kleos reload`              | `kleos.admin.reload` | 重新读取主配置、语言、品质、称号和界面 |

`/kl` 和 `/titles` 是 `/kleos` 的别名，后面的子命令与权限相同。

## 发放时长

省略时长时默认永久发放，也可以使用 `permanent`、`forever` 或 `永久`：

```text
/kleos give Player night_watcher
/kleos give Player night_watcher permanent
```

限时称号支持组合单位：

| 单位  | 含义 | 示例      |
|-----|----|---------|
| `s` | 秒  | `30s`   |
| `m` | 分钟 | `45m`   |
| `h` | 小时 | `1h30m` |
| `d` | 天  | `7d`    |
| `w` | 周  | `2w3d`  |

单次解析的最长时长为 3650 天。

## 续期规则

- 尚未到期的限时称号，从原到期时间继续累加；
- 已经过期的称号，从当前时间重新计算；
- 永久称号再次发放有限时长时，仍然保持永久；

撤销玩家当前佩戴的称号时，Kleos 会同时取消佩戴并移除对应属性。

## 重载范围

`/kleos reload` 会重新读取主配置、语言、品质、称号和 `ui/titles.yml`。数据库类型、连接地址、工作线程数和连接池设置变更后，需要完整重启服务器。
