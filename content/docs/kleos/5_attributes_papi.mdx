# 属性与 PAPI

## 属性加成

称号的属性由 `attributes.provider` 指定的 ArcartX 属性提供器处理。下面的示例使用 Symphony：
不同提供器的写法不同，像是AP、AXH一般使用直接lore描述，Symphony使用表达式，详情可查看 [Symphony文本属性来源](/docs/symphony/30_source_api#从文字读取)

```yaml
attributes:
  provider: Symphony
  values:
    - "symphony:max_health add 4"
    - "symphony:movement_speed add 3%"
```

以下时机会自动校正属性：

- 玩家数据加载完成；
- 佩戴或取消佩戴称号；
- 当前称号被移除或到期；
- 玩家重生；
- 插件定期检查状态；

属性提供器暂不可用时，佩戴状态仍会保存。提供器恢复后，Kleos 会重新应用当前称号属性。

## PlaceholderAPI

安装 PlaceholderAPI 后可以使用：

| 变量               | 返回内容                 |
|------------------|----------------------|
| `%kleos_title%`  | 当前称号的 `papi-content` |
| `%kleos_name%`   | 当前称号名称               |
| `%kleos_id%`     | 当前称号 ID              |
| `%kleos_expiry%` | 到期日期或“永久”            |

玩家没有佩戴有效称号时，这些变量返回空文本。

随插件提供的称号示例把 `papi-content` 设为 FontIcon 控制串。要显示对应图标，需要创建匹配的 FontIcon，并启用 ArcartX 全局文字渲染器；
只用于聊天栏时也可以配合 Chorus。若不使用图标，可把称号文件中的 `papi-content` 改为普通文字，例如 `"&9黑夜守望者"`。

修改 `papi-content` 后执行 `/kleos reload`。如果聊天或计分板仍显示旧内容，请再刷新使用变量的目标插件。
