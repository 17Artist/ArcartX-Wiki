# 玩家使用

拥有 `kleos.open` 权限的玩家可以执行：

```text
/kleos open
```

界面显示玩家当前可查看的称号。玩家可按拥有状态、品质筛选，也可以搜索称号名称、介绍或 ID。

## 称号状态

| 状态  | 说明               |
|-----|------------------|
| 佩戴中 | 当前正在生效的称号        |
| 已拥有 | 可以佩戴，且仍在有效期内     |
| 已过期 | 曾经获得，现已过期        |
| 未拥有 | 尚未获得；是否显示由服主配置决定 |

列表默认按以下顺序排列：

1. 佩戴中；
2. 已拥有；
3. 已过期；
4. 未拥有；

同一状态内先按称号 `priority` 从高到低排列，再按名称和 ID 排列。

服主关闭 `ui.show-unowned` 后，未拥有和已过期的称号都不会显示。

## 佩戴与取消佩戴

选择仍在有效期内的称号后，可以在详情区域佩戴；已经佩戴的称号可以在同一位置取消佩戴。

## 有效期

- 永久称号显示“永久”；
- 限时称号显示服务端计算后的到期日期；
- 未拥有的称号显示 `—`。

称号到期后不能再佩戴。如果到期的是当前称号，Kleos 会取消佩戴并移除对应属性加成。

## 属性暂不可用

属性提供器暂不可用时，佩戴状态仍会保存，界面会显示提示。提供器恢复后，Kleos 会定期重新尝试应用属性。
