# 界面协议

## 通讯总览

| 方向       | 名称         | 数据      | 用途         |
|----------|------------|---------|------------|
| 服务端 → UI | `settings` | 标题与显示上限 | 初始化或更新界面设置 |
| 服务端 → UI | `stats`    | 模式与总人数  | 更新人数和群组状态  |

## `settings`

```json
{
  "title": "在线玩家",
  "limit": 80
}
```

| 字段      | 类型     | 说明                    |
|---------|--------|-----------------------|
| `title` | String | 界面标题                  |
| `limit` | Number | 显示上限，范围 `1..80`，默认 80 |

UI 首次就绪、设置变化或重载时发送。关闭后重新打开 HUD 会重新初始化；同一 UI 实例重复就绪不会重复发送。

## `stats`

```json
{
  "scope": "network",
  "total": 120
}
```

| 字段      | 类型     | 说明                            |
|---------|--------|-------------------------------|
| `scope` | String | `local`、`network` 或 `offline` |
| `total` | Number | 非负总人数；群组信息不可用时为 0             |

初次初始化时发送一次，此后每 5 秒检查，内容变化时才发送。该包仅包含统计，不含 UUID、名称、延迟、服务器或玩家数组。

| `scope`   | `total` 含义    | 显示方式                   |
|-----------|---------------|------------------------|
| `local`   | 当前观看者可见的本服人数  | 显示 `列表 N`，N 为实际显示条目数   |
| `network` | 本服可见人数加公开远端人数 | 显示 `在线 N`，N 为 `total`  |
| `offline` | 0，未知群组总数      | 保留当前客户端名单，提示“群组信息暂不可用” |

`scope` 只影响人数与提示，名单来源始终为原版接口。`settings` 与 `stats` 的到达顺序不影响最终显示。
