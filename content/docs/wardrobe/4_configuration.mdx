# 配置文件

Wardrobe 的配置位于 `plugins/Wardrobe/`：

```text
Wardrobe/
├─ config.yml
├─ database.yml
├─ language.yml
├─ license.yml
├─ wardrobe.db
├─ fashions/
│  └─ example.yml
└─ ui/
   └─ wardrobe.yml
```

## 授权配置

首次启动生成 `license.yml`：

```yaml
licenseId: 你的许可证ID
licenseKey: "你的许可证密钥"
```

## 主配置

默认 `config.yml`：

```yaml
ui:
  page-size: 10

expiry:
  scan-seconds: 60

presets:
  max: 3
  default-unlocked: 1
  unlocks:
    "1":
      provider: Vault
      cost: 1000.0
      enabled: true
    "2":
      provider: Vault
      cost: 2000.0
      enabled: true
```

## 数据库配置

默认 `database.yml`：

```yaml
type: sqlite
sqlite-file: wardrobe.db
worker-threads: 4

mysql:
  host: 127.0.0.1
  port: 3306
  database: wardrobe
  username: root
  password: ""
  parameters: useUnicode=true&characterEncoding=utf8&serverTimezone=UTC
  pool-size: 6
```

| 配置                    | 说明                                 |
|-----------------------|------------------------------------|
| `type`                | `sqlite` 或 `mysql`                 |
| `sqlite-file`         | SQLite 文件名，相对于 `plugins/Wardrobe/` |
| `worker-threads`      | 数据读写任务使用的线程数，范围 `2`～`8`            |
| `mysql.host`          | MySQL 地址                           |
| `mysql.port`          | 端口，范围 `1`～`65535`                  |
| `mysql.database`      | 数据库名                               |
| `mysql.username`      | 用户名                                |
| `mysql.password`      | 密码                                 |
| `mysql.parameters`    | JDBC 连接参数                          |
| `mysql.pool-size`     | 连接池大小，范围 `2`～`32`                  |


<Callout type="warn">
`database.yml` 中的设置修改后必须完整重启。
</Callout>

## 界面与到期检查

| 配置                    | 说明            | 范围          |
|-----------------------|---------------|-------------|
| `ui.page-size`        | 每页显示的时装数      | `1`～`30`    |
| `expiry.scan-seconds` | 检查限时时装到期状态的间隔 | `5`～`300` 秒 |

到期检查只负责及时刷新在线玩家状态。

## 预设栏位

| 配置                              | 说明              | 范围                |
|---------------------------------|-----------------|-------------------|
| `presets.max`                   | 每名玩家最多拥有的预设数    | `1`～`20`          |
| `presets.default-unlocked`      | 新玩家默认解锁的预设数     | `1`～`presets.max` |
| `presets.unlocks.<索引>.enabled`  | 是否允许解锁该预设       | `true` / `false`  |
| `presets.unlocks.<索引>.provider` | ArcartX 经济提供器名称 | 最多 64 个字符         |
| `presets.unlocks.<索引>.cost`     | 解锁费用            | 大于等于 `0`          |

解锁索引从 `1` 开始配置，因为索引 `0` 是第一个默认预设。例如 `presets.max: 3` 时，可配置的解锁项是 `"1"` 和 `"2"`。玩家只能按顺序解锁下一个预设。

## 重新读取与备份

执行 `/wardrobe reload` 可以重新读取：

- `config.yml`；
- `database.yml`，仅检查设置，连接和任务线程需重启后变更；
- `language.yml`；
- `fashions/` 下的时装目录；
- `ui/wardrobe.yml`；
- 到期检查任务和在线玩家衣柜状态。
