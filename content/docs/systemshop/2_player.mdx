# 玩家使用

玩家需要 `systemshop.use` 权限，通过以下任一命令使用商城：

```text
/ss open
/sshop open
/systemshop open
```

直接输入根命令会显示帮助。

## 浏览与收藏

商城界面支持：

- 查看全部商品或切换商品分组；
- 翻页浏览当前分组；
- 查看商品详情、奖励和当前限购情况；
- 收藏或取消收藏商品；
- 从“收藏”入口查看已收藏商品。

## 优惠券

每张优惠券有不同的到期时间。结算时最多选择一张券。

优惠券有两种模式：

| 模式   | 说明                              |
|------|---------------------------------|
| 固定抵扣 | 从一个商品单位中减去指定金额，最多减到该单位价格为零      |
| 倍率折扣 | 对一个商品单位按指定倍率计算折扣，例如 `0.80` 表示八折 |

一张券只优惠一个商品单位(商品单位指的是，比如买64个商品，只优惠第一个)。例如商品单价 100、购买 3 件并使用八折券，实付为 `300 - 20 = 280`。

## 限购

商品可以同时设置个人限购和全服限购，购买须同时满足两种额度。

| 周期        | 说明          |
|-----------|-------------|
| `NEVER`   | 永久累计        |
| `DAILY`   | 每个自然日重新统计   |
| `WEEKLY`  | 每周一开始新的统计周期 |
| `MONTHLY` | 每个自然月重新统计   |

日、周、月按服务器配置的 `time-zone` 计算。
