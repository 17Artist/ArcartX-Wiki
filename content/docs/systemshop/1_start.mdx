# 说明与安装

SystemShop 向服务器提供**系统商城** 功能。服主可 YAML 配置商品、优惠券与限购规则，玩家可通过 UI 浏览、收藏并购买商品。

<Callout type="warn">
**SystemShop 是付费插件。** 使用时需要填写购买该插件后取得的授权ID和密钥。
</Callout>

## 核心能力

| 能力   | 说明                           |
|------|------------------------------|
| 商品目录 | 支持多个分组、商品分页、收藏与上下架           |
| 灵活奖励 | 可组合发放物品、货币和控制台命令             |
| 优惠券  | 支持固定抵扣、倍率折扣、适用范围与有效期         |
| 限购   | 支持个人与全服限购，可按永久、日、周或月统计       |
| 条件控制 | 使用 Aria 根据玩家、商品、时间等信息限制购买或用券 |


## 安装条件

- Java 17+；
- Minecraft 1.18.2+；
- ArcartX 2.6.73+；
- SystemShop 有效授权；
- 已在 ArcartX 中注册的经济提供者(默认包含 Vault PlayerPoints Rondo)。

## 安装步骤

<Steps>

<Step>

### 安装插件

确认 ArcartX 已正常启用，将 SystemShop JAR 放入服务端 `plugins/`，然后完整启动一次服务器。

</Step>

<Step>

### 填写授权

首次启动会生成 `plugins/SystemShop/license.yml`。填写购买 SystemShop 后取得的授权ID和密钥，再完整重启：

```yaml
licenseId: 你的许可证ID
licenseKey: "你的许可证密钥"
```

</Step>

<Step>

### 选择存储方式

单服保留默认 SQLite。群组服让所有子服连接同一套 MySQL 与 Redis，并为每个子服设置不同的 `server-id`。

</Step>

<Step>

### 配置商品

修改 `catalog/groups.yml`、`catalog/products/` 与 `catalog/coupons/`。默认文件用于展示格式，其中的货币途径、图标和命令需要按服务器实际情况替换。

</Step>

<Step>

### 检查启动结果

确认控制台没有授权、数据库、Redis、商品目录或界面注册错误，并检查目录已经生成：

```text
plugins/SystemShop/
├─ license.yml
├─ config.yml
├─ database.yml
├─ redis.yml
├─ language.yml
├─ systemshop.db
├─ catalog/
│  ├─ groups.yml
│  ├─ products/
│  └─ coupons/
└─ ui/
   └─ system_shop.yml
```

`systemshop.db` 只在 SQLite 模式下使用。

</Step>

</Steps>
