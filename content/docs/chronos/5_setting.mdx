import { Callout } from 'fumadocs-ui/components/callout';

`setting.yml` 指定配置版本和默认职业：

```yaml
schema_version: 3
default_profession: "chronos:common"
```

| 字段                   | 说明                                                                                      |
|----------------------|-----------------------------------------------------------------------------------------|
| `schema_version`     | 当前必须为 `3`。不是 3 时拒绝加载。                                                                   |
| `default_profession` | 创建玩家运行数据时使用的 Chronos 职业 ID；省略时为 `chronos:common`，不能留空，必须对应 `professions/*.yml` 内的 `id`。 |

`professions/common.yml` 定义的是普通职业 `chronos:common`。它没有全局选择器或特殊回退权限，使用与其他职业相同的允许列表和路由规则。新安装和旧配置迁移后的 `default_profession` 都指向它。修改后需重载配置或重启服务器；重载时，已有玩家仍保留当前职业，只有原职业已被删除时才回退到新的默认职业。该设置不负责保存玩家的职业选择，外部职业框架仍通过快照提供玩家职业。

<Callout type="info">
控制器默认值、按主手 NBT 路由和复合触发器已经全部移入每个职业自己的 `controllers` 节点。详见 [职业与技能配置](/docs/chronos/5_profession)。
</Callout>

<Callout type="warn">
不要把旧字段重新写回 `setting.yml`。旧格式只由启动前的一次性迁移器读取；正式运行阶段只接受 schema 3。
</Callout>
