## MythicMobs 词条

Chronos 会在 MythicMobs 加载时自动注册两个技能机制。它们都是**面向目标实体**的机制，只对玩家目标生效。

| 机制（别名）                          | 作用                     | 参数                                                  |
|---------------------------------|------------------------|-----------------------------------------------------|
| `chronosControlledState`（`ccs`） | 让目标玩家进入**受控状态**（尊重霸体）  | `state`/`s`：状态ID；`duration`/`d`：毫秒，默认 `-1`（用状态自带时长） |
| `chronosTryEnterState`（`ctes`）  | 让目标玩家**尝试进入状态**（走完整校验） | `state`/`s`：状态ID                                    |

```yaml
# MythicMobs 技能：命中玩家时打进受击，持续 800ms
击飞技能:
  Skills:
  - chronosControlledState{state=受击;duration=800} @target
  # 等价写法：- ccs{s=受击;d=800} @target

# 让玩家触发一个受规则约束的状态（会被冷却/条件拦下）
触发反击:
  Skills:
  - chronosTryEnterState{state=反击} @target
```

<Callout type="info">
    这两个机制内部对应 `tryEnterControlledState` 和 `tryEnterState`：前者检查霸体，但跳过目标状态的条件与冷却校验，也不写入该状态的冷却；后者执行条件与冷却校验。异步施放时，状态变更会调度回主线程。机制返回 `SUCCESS` 表示已调用或已调度状态变更，不保证状态已经进入。
</Callout>

状态 ID 在目标玩家当前生效的控制器内解析。这两个机制直接操作状态，不会按技能槽发起技能释放，也不会经过目标选择或外部职业资源准入。

`chronosControlledState` 的正数 `duration` 覆盖状态定义时长，但仍按该状态的 `speed` 缩放；小于或等于 0 时使用状态定义时长。例如 `duration=800`、状态 `speed=2` 时，计划持续时间为 400ms。
