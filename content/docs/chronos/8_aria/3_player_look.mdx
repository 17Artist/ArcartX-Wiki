---
title: 朝向吸附
description: Chronos 提供的近战朝向吸附语句（PlayerLook）
---

import { Callout } from 'fumadocs-ui/components/callout';

- 以下语句均由 **Chronos 插件**提供，目标对象为**玩家**（`Player{:aria}`）。
- 这组语句用于**近战吸附**：出手前把玩家朝向自动转向目标，让攻击更容易命中。
- 三个语句只调整水平朝向（yaw），不调整俯仰角（pitch）。`strength{:aria}` 的取值范围为 **0 ~ 1**（超出会被自动钳制）：`0` 保持当前水平朝向，`1` 将目标水平朝向发给客户端，中间值按比例插值。
- 常见用法是放在攻击状态的 `execute` 里、在挥砍判定之前调用。
- 三个方法还接受末尾的可选 `camera` 参数，默认 `0`，作为相机跟随强度原样发给 ArcartX，由匹配客户端的自由相机实现处理。它与玩家朝向的 `strength` 参数独立；`turnToCone` 中应放在第四个参数，例如 `self.turnToCone(5.0, 120, 0.7, 0.4){:aria}`。

## `turnToTarget(target, strength){:aria}`
- 把玩家朝向吸附到**指定的目标生物**。
<Callout type="info">
    - **对象**：Player
    - **参数**：
        - `target` — 生物对象（`LivingEntity{:aria}`），通常来自实体选择器
        - `strength` — 吸附强度（0 ~ 1）
    - **返回值**：无
    - **调用示例**
    ```aria
    var.enemy = self.getNearestLivingEntity(5.0)
    self.turnToTarget(var.enemy, 0.8)
    ```
</Callout>

## `turnToNearby(radius, strength){:aria}`
- 从 `radius` 指定的周围包围盒候选中，按三维位置距离寻找最近生物并吸附朝向；没有候选时不做操作。没有额外的球形距离过滤。
<Callout type="info">
    - **对象**：Player
    - **参数**：
        - `radius` — 各轴周围搜索范围（方块）
        - `strength` — 吸附强度（0 ~ 1）
    - **返回值**：无
    - **调用示例**
    ```aria
    self.turnToNearby(6.0, 0.6)
    ```
</Callout>

## `turnToCone(radius, angle, strength){:aria}`
- 从周围包围盒候选中，按水平面上的朝向夹角筛选，再取三维位置距离最近的生物并吸附。这里忽略俯仰角，与实体选择器 `getLivingEntitiesInCone` 的三维夹角判定不同；同样没有额外球形距离过滤。
<Callout type="info">
    - **对象**：Player
    - **参数**：
        - `radius` — 各轴周围候选范围（方块）
        - `angle` — 扇形总角度（度数，例如 `120` 表示正前方左右各 60°）
        - `strength` — 吸附强度（0 ~ 1）
    - **返回值**：无
    - **调用示例**
    ```aria
    self.turnToCone(5.0, 120, 0.7)
    ```
</Callout>
