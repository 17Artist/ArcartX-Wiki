```yaml
category: "克洛诺斯"

keys:
  普通战技: "X"
  位移技: "Q"
  终结技: "R"
  闪避: "LEFT_ALT"

# 这里是按键 ID 列表，不是固定三槽结构。
skill_slots:
  - "普通战技"
  - "位移技"
  - "终结技"
```

`keys` 的键名是稳定的按键 ID，值只是默认物理键；玩家可以在客户端改绑。`skill_slots` 中每一项都必须非空、不能重复，并且必须先在 `keys` 中注册。

## 普通输入与技能槽的区别

未列入 `skill_slots` 的按键继续进入当前控制器的 raw combo：

```yaml
combo:
  闪避:
    input:
      type: KEY_PRESS
      value: "闪避"
```

列入 `skill_slots` 的按键不会进入 raw combo，而是走：

```text
按键 ID
  -> 当前职业快照 loadout[按键 ID]
  -> 当前职业的技能定义
  -> 当前控制器对应 route
  -> 可选目标选择
  -> 外部职业准入
  -> 具名连招链
```

<Callout type="info">
槽位数量和名称完全由 `keys`、`skill_slots` 与外部职业快照的 `loadout` 决定。可以是 1、4、8 个，也可以使用 `primary`、`mobility`、`ultimate` 等名称；Chronos 没有“三个技能槽”的常量或限制。
</Callout>

## 输入阶段

| 客户端包                     | 技能触发值     | raw combo 类型       |
|--------------------------|-----------|--------------------|
| 短按释放 `key_click`         | `PRESS`   | `KEY_PRESS`        |
| 长按达到阈值 `key_hold`        | `HOLD`    | `KEY_HOLD`         |
| 长按后释放 `key_hold_release` | `RELEASE` | `KEY_HOLD_RELEASE` |

键盘长按阈值由客户端决定，当前为约 500ms。

特殊选择器的推荐组合：

- `PRESS_CONFIRM`：技能 `trigger: PRESS`，第一次短按开始选择，第二次短按向当前选择实例发送 `CONFIRM`。
- `HOLD_RELEASE`：技能 `trigger: HOLD`，达到长按阈值开始选择，松开时发送 `RELEASE`；短按不会启动选择。
- `PRESS_AUTO`：技能 `trigger: PRESS`，Provider 启动后自行决定何时提交服务端选择，不等待第二次按键。


详见 [职业与技能配置](/docs/chronos/5_profession) 与 [目标选择器接入](/docs/chronos/9_target_selector)。
