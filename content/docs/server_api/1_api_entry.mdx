## ArcartXAPI

- `ArcartXAPI` 是ArcartX所有服务端API的统一入口，位于 `priv.seventeen.artist.arcartx.api` 包下。
- 它是一个单例对象，所有方法均为静态方法，可直接调用。

## `getUIRegistry(){:java}`
- 获取UI注册管理器

<Callout type="info">
- **参数**：无
- **返回值**：`ArcartXUIRegistry`
- **调用示例**
```java
ArcartXUIRegistry registry = ArcartXAPI.getUIRegistry();
```
</Callout>
