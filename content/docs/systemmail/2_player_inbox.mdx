# 玩家收件箱

玩家可以使用以下任一命令打开收件箱：

```text
/systemmail
/smail
/mail
/sm
/系统邮件
/邮箱
```

## 查找邮件

收件箱支持三种筛选：

| 筛选  | 显示内容        |
|-----|-------------|
| 全部  | 当前仍可查看的全部邮件 |
| 未读  | 尚未打开详情的邮件   |
| 含附件 | 有附件可以领取的邮件  |

搜索会同时匹配邮件标题和发件人。打开详情后，邮件会自动标记为已读。

## 领取附件

SystemMail 会先检查本次所需的全部背包空槽；空间不足时，本次领取会直接拒绝，不会先发货币、执行命令或只领取一部分物品。

常见领取结果：

| 结果                  | 含义                      |
|---------------------|-------------------------|
| `COMPLETED`         | 全部附件领取完成                |
| `INVENTORY_FULL`    | 背包空槽不足，任何附件都没有开始领取      |
| `NOTHING_CLAIMABLE` | 没有剩余附件可领                |
| `PLAYER_OFFLINE`    | 处理时玩家已经离线               |
| `EXPIRED`           | 邮件已过期，且当前界面没有有效宽限资格     |
| `QUARANTINED`       | 某项外部奖励的结果无法自动确认，需要管理员处理 |


## 邮件到期时正在查看

默认配置下，如果玩家在邮件到期前已经成功打开详情，当前界面会保留最多 20 分钟的固定领取宽限。

这段宽限只属于当前玩家、当前收件箱会话和当前邮件：

- 切换到其他邮件、关闭收件箱或退出服务器后立即失效；
- 重复点击不会延长时间；
- 过期邮件不会重新出现在列表、搜索或未读数中；
- 其他插件通过公开 API 领取时不使用这段宽限。

服主可以通过 `mail.ui-claim-expiry-grace-minutes` 调整或关闭这一行为。

## 删除邮件

没有待领取附件的邮件可以直接删除。只要仍存在未领取、处理中或隔离的附件，服务端就会拒绝删除，避免资产丢失。

删除后的记录会保留一段时间供系统维护，保留天数由 `mail.trash-retention-days` 控制。
