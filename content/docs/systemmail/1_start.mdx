# 说明与安装

SystemMail 是面向 ArcartX 服务器的**系统邮件插件**。管理员和其他服务端插件可以向玩家发送物品、货币或命令奖励；玩家通过 UI 收件箱查看并领取。

<Callout type="warn">
**SystemMail 为 ArcartX 高级会员专属插件。** 使用时需要有效授权，并依赖 ArcartX。
</Callout>

SystemMail 只处理“系统 → 玩家”邮件，不提供玩家互寄功能。

## 核心能力

| 能力    | 说明                                     |
|-------|----------------------------------------|
| 玩家收件箱 | 支持未读、附件筛选、搜索、详情、附件领取和删除                |
| 管理中心  | 使用箱子界面创建与保存草稿、发送邮件、查看记录和处理异常附件         |
| 多种附件  | 支持物品、ArcartX 货币和领取后命令                  |
| 单服与跨服 | 单服使用 SQLite；多服共享 MySQL，并用 Redis 通知在线子服 |
| 插件接入  | 为其他服务端插件提供异步 Java/Kotlin API           |

## 安装条件

- Java 17+；
- Minecraft 1.18.2+；
- ArcartX；
- 高级会员有效授权。

## 安装步骤

<Steps>

<Step>

### 放入插件

将 SystemMail JAR 放入服务端 `plugins/`，然后完整启动一次服务器。

</Step>

<Step>

### 填写授权

打开首次生成的 `plugins/SystemMail/license.yml`，填写自己的 `licenseId` 与 `licenseKey`，
再完整重启。

</Step>

<Step>

### 选择存储模式

单服保留默认 SQLite。群组服让所有子服连接同一套 MySQL 与 Redis，并为每个子服设置不同
的 `server-id`。

</Step>

<Step>

### 检查启动结果

确认控制台没有授权、数据库、Redis 或界面注册错误，并检查 `plugins/SystemMail/` 已生成：

```text
config.yml
database.yml
redis.yml
mail.yml
language.yml
license.yml
ui/inbox.yml
ui/hud.yml
```

</Step>

</Steps>

## 单服 SQLite

`config.yml`：

```yaml
server-id: server-1
time-zone: Asia/Shanghai
```

`database.yml`：

```yaml
type: sqlite
sqlite-file: system-mail.db
```

`redis.yml`：

```yaml
enabled: false
```

SQLite 数据库位于 `plugins/SystemMail/`，且不能同时启用 Redis。

## 多服 MySQL + Redis

每个子服使用不同的 `config.yml -> server-id`。所有子服的 `database.yml` 指向同一 MySQL：

```yaml
type: mysql
mysql:
  host: 127.0.0.1
  port: 3306
  database: system_mail
  username: system_mail
  password: change-me
```

所有子服的 `redis.yml` 指向同一 Redis，并使用相同键前缀：

```yaml
enabled: true
host: 127.0.0.1
port: 6379
database: 0
key-prefix: 'systemmail:'
```

<Callout type="info">
MySQL 保存邮件、附件和领取状态。Redis 只负责快速通知；短暂断线时，SystemMail 会继续 从 MySQL 检查新邮件。
</Callout>
