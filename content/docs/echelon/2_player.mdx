# 玩家等级

## 查询命令

| 命令              | 用途                     |
|-----------------|------------------------|
| `/echelon show` | 查看自己的等级、当前经验、升级所需经验和称号 |

查询结果类似：

```text
Steve：Lv.12 经验 180/400 称号 渐入佳境
```

玩家刚进入服务器时，等级数据可能仍在读取。看到“等级数据仍在加载”后，稍等片刻重新查询即可。

## 经验与等级

Echelon 会保存玩家获得的总经验，并根据当前经验曲线计算：

- 当前等级；
- 当前等级内已有经验；
- 升到下一级需要的经验；
- 当前阶段称号。

达到满级后，多出的经验不会继续计入。服主修改经验曲线时，已经获得的总经验不会丢失，显示等级会按照新曲线重新计算。

## 离线升级

管理员和其他插件可以给离线玩家增加经验。离线期间产生的升级事件会保留到玩家下次进入服务器时触发；使用共享 MySQL 时，进入任意安装了 Echelon 的子服都可以触发。

如果其他插件在玩家登录前通过 API 将其设到更低等级，已经失效的旧升级提示不会再触发。
