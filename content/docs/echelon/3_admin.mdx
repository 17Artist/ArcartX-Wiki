# 管理与等级礼包

管理主命令为 `/echelonadmin`，可以简写为 `/eadmin`。

## 命令与权限

| 命令                                    | 权限                      | 用途                |
|---------------------------------------|-------------------------|-------------------|
| `/echelonadmin show <在线玩家>`           | `echelon.admin.show`    | 查看一名在线玩家的等级       |
| `/eadmin addexp <玩家名或UUID> <经验> [来源]` | `echelon.admin.addexp`  | 为在线或离线玩家增加经验      |
| `/eadmin reload`                      | `echelon.admin.reload`  | 重新读取等级、提示和联动设置    |
| `/eadmin rewards`                     | `echelon.admin.rewards` | 打开等级礼包列表，仅游戏内可用   |
| `/eadmin rewardcreate <等级>`           | `echelon.admin.rewards` | 创建礼包并打开编辑器，仅游戏内可用 |
| `/eadmin deliveries`                  | `echelon.admin.status`  | 查看等级礼包邮件发送情况      |

OP 默认拥有这些权限。

## 查询其他玩家

```text
/echelonadmin show Steve
```

该命令只能查询在线玩家。

## 增加经验

```text
/eadmin addexp Steve 250
/eadmin addexp Steve 250 quest:chapter_1
```

经验必须是大于 0 的整数。最后一个参数是可选的经验来源，建议使用稳定、容易识别的名称，例如 `quest:chapter_1`、`event:summer`。

离线玩家的查找规则：

- 玩家以前进入过服务器时，可以使用最后记录的玩家名；
- 玩家从未被 Echelon 记录时，需要使用 UUID。

玩家达到满级后，多出的经验不会计入，命令会显示被舍弃的数量。

## 创建等级礼包

等级礼包依赖 SystemMail。先完成 [SystemMail 安装](/docs/systemmail/1_start)，再在 Echelon 配置中启用对应联动。

<Steps>

<Step>

### 创建礼包

```text
/eadmin rewardcreate 10
```

等级必须处于当前等级上限内。同一级只能有一个礼包。

</Step>

<Step>

### 编辑内容

```text
/eadmin rewards
```

点击礼包后，可以设置显示名、启用状态、发件人、头像、邮件标题、正文、领取期限以及三种附件。

</Step>

<Step>

### 保存修改

编辑完成后点击“保存修改”。点击“放弃未保存修改”会丢弃本次改动。


</Step>

</Steps>

编辑文字时，界面会暂时关闭并等待聊天输入：

- 输入 `取消` 或 `cancel` 返回；
- 可清空的字段输入 `清空` 或 `clear`；
- 邮件正文使用 `\n` 表示换行。

编辑器会检查格式和长度，超出限制时会要求重新输入。
### 邮件占位符

| 写法         | 发送时替换为  |
|------------|---------|
| `{player}` | 玩家名     |
| `{uuid}`   | 玩家 UUID |
| `{level}`  | 礼包等级    |
| `{reward}` | 礼包显示名   |

这些占位符可以用于发件人、标题、正文和命令附件。

### 物品附件

进入物品附件页后，点击玩家背包中的物品即可添加。原物品不会被扣除。

### 货币附件

```text
货币ID|数量|显示名称|图标路径
```

例如：

```text
vault|1000|金币|
```

货币 ID 必须已经在 ArcartX 中注册。ArcartX 内置 Vault 和 PlayerPoints 两种常见货币来源；使用 Rondo 时也可以填写 Rondo 注册的货币 ID。

### 命令附件

```text
console|显示名称|图标路径|命令
player|显示名称|图标路径|命令
```

`console` 由控制台执行，`player` 以领取玩家身份执行。命令开头的 `/` 可以省略：

```text
console|发放称号||lp user {player} permission set title.level
```

每个礼包最多保存 32 个命令附件。

### 领取期限

点击“邮件领取期限”会依次切换：

```text
永久 → 1 天 → 7 天 → 30 天 → 永久
```

## 发放规则

- 玩家升级并达到已启用礼包对应的等级时发送；
- 一次跨越多个礼包等级时，每个符合条件的等级分别发送一份；
- 同一玩家的同一级礼包只发送一次；
- 新建礼包不会向已经达到该等级的玩家补发；
- 修改礼包只影响之后生成的邮件，已经等待发送的邮件保留原内容。

## 查看发送情况

```text
/eadmin deliveries
```

命令会显示待发送、已发送和已停止重试的邮件数量。
<Callout type="info">
`/eadmin reload` 不会重载数据库配置。数据库相关改动需要完整重启服务器。
</Callout>
