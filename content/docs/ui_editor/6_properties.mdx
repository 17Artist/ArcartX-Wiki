## 属性面板与 `~` 规则

**核心概念：控件的几乎所有属性值都是 Aria 脚本表达式**，每帧求值。这带来两条规则：

1. **纯文字 / 颜色 / 路径 / 锚点 / 枚举 → 值前加 `~`**：`~255,0,0`、`~gui/bg.png`、`~middle_center`。忘加 `~` 会被当脚本编译——通常报错或得到空值。
2. **想要动态 → 直接写脚本**：`width` 填 `Player.getHealth() * 10`，血量变化时宽度实时变化。

<Callout type="info">
数字和布尔两种写法都行（`100` 与 `~100` 等价）。属性面板中的颜色 / 枚举选择器会自动帮你带上 `~`。
</Callout>

## 属性编辑技巧

- 数字输入框上**按住左键左右拖动**即可微调数值（`Shift` = ×10 粗调，`Alt` = ×0.1 精调）。
- 每个属性可点开**代码编辑**进入脚本模式：Aria 语法高亮、上下文补全（命名空间 → 函数、对象 → 成员）、实时语法诊断（红下划线）。
- **动作（Action）**：控件的事件脚本（点击 / 悬停 / 每帧等）。注意 **UI 级事件**（open / close / tick / seconds / resize 等，写在 UI 设置里）与**控件级事件**（click / enter / leave / textChange 等）是两套。
- **特效（Effect）**：描边 / 阴影 / 霓虹 / 渐变 / 流光 / 能量 / 水波 / 扇形裁剪等，每个参数同样可以是脚本。
