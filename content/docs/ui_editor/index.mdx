## 这是什么

**ArcartX UI Editor** 是用于创作 ArcartX Mod 自定义 UI（HUD / 菜单）的**可视化编辑器**，提供实时预览、Aria 脚本补全、以及 AI 辅助设计。

-  **所见即所得**：拖拽摆放控件，画布实时渲染，接近真机效果。
-  **脚本驱动**：控件属性即 Aria 表达式，每帧求值，轻松做动态界面（血量条、冷却遮罩……）。
-  **AI 辅助**：内置 MCP，可让 Claude Code 等工具直接操控编辑器边改边截图自检。
-  **多语言**：简中 / 繁中（台/港）/ 英 / 韩即时切换。

<Callout type="warn">
**ArcartX UI Editor 为 ArcartX 高级会员专属工具。** 开通高级会员即可下载使用：[前往高级会员页面 →](https://arcartx.com/resources/67/)
</Callout>

<Callout type="info">
本手册讲解**编辑器**的使用。更深入的 UI 配置语法与脚本，请配合官方 Wiki 的 [ArcartX · 客户端 UI](/docs/arcartx_v2/8_ui) 与 [Aria 脚本引擎](/docs/aria) 章节阅读。适用版本：编辑器 2.0.0+（Aria 脚本引擎版）。
</Callout>
