## 画布操作

| 操作     | 方式                           |
|--------|------------------------------|
| 平移视图   | 右键拖动                         |
| 缩放视图   | Ctrl + 滚轮（以鼠标为中心）            |
| 选中控件   | 左键点击                         |
| **多选** | Shift + 点击逐个加选；空白处**左键拖框**框选 |
| 移动控件   | 拖拽；或方向键微调（Shift 加速）          |
| 缩放控件   | 拖拽选中框四角手柄（仅主选中控件）            |
| 智能吸附   | 拖拽时自动对齐邻近控件 / 参考线，显示红色吸附线    |
| 实时数值   | 拖拽 / 微调时控件旁浮动显示 x,y 与 w,h    |

## 多选与对齐

选中 2 个以上控件时，画布上方出现**对齐工具条**——左 / 水平居中 / 右、上 / 垂直居中 / 下 六向对齐；3 个以上再提供水平 / 垂直等距分布。

多选状态下移动、删除、复制、粘贴均作用于全体，且整组操作**只占一个撤销步**。

<Callout type="info">
属性值为脚本表达式的控件无法直接拖动（位置由脚本决定），可先临时改为字面量。
</Callout>
