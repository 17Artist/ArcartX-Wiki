## 快捷键总表

| 快捷键                                  | 功能                 |
|--------------------------------------|--------------------|
| `Ctrl+N` / `Ctrl+O` / `Ctrl+S`       | 新建 / 打开 / 保存       |
| `Ctrl+Z` / `Ctrl+Y` / `Ctrl+Shift+Z` | 撤销 / 重做 / 重做       |
| `Ctrl+C` / `Ctrl+X` / `Ctrl+V`       | 复制 / 剪切 / 粘贴（支持多选） |
| `Ctrl+D`                             | 复制并粘贴选中控件          |
| `Delete` / `Backspace`               | 删除选中控件（支持多选）       |
| `Ctrl+A`                             | 全选顶层控件             |
| `Esc`                                | 取消选择               |
| 方向键 / `Shift`+方向键                    | 微调位置 / 大步微调（支持多选）  |
| `Shift`+点击                           | 加选 / 减选            |
| `Ctrl`+滚轮                            | 缩放画布               |
