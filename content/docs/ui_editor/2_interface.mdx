## 界面总览

![主界面](/ui_editor/main.png)

- **控件树**（左）：控件层级结构。拖拽重排、右键菜单（复制 / 剪切 / 粘贴 / 重命名 / 删除）、双击重命名。
- **画布**（中）：所见即所得编辑区。
- **属性面板**（右）：选中控件的属性、动作（事件脚本）、特效编辑。
- **预览模式**：顶栏切换。编辑模式用于摆放，预览模式以接近真机的节奏运行脚本与动画。
