# 配置文件

Appearance 的配置位于 `plugins/Appearance/`：

```text
Appearance/
├─ config.yml
├─ database.yml
├─ language.yml
├─ license.yml
├─ appearance.db
├─ models/
│  └─ example.yml
└─ ui/
   └─ appearance.yml
```

## 主配置

默认 `config.yml`：

```yaml
default-model: "default"

page-size: 10
expiration-check-seconds: 30
```

数据库连接位于独立的 `database.yml`：

```yaml
type: "sqlite"
sqlite-file: "appearance.db"
worker-threads: 4

mysql:
  host: "127.0.0.1"
  port: 3306
  database: "arcartx"
  username: "root"
  password: "change-me"
  parameters: "useSSL=false&allowPublicKeyRetrieval=true&serverTimezone=UTC&characterEncoding=utf8"
  pool-size: 6
  connection-timeout-ms: 10000
```

## 默认外观

`default-model` 决定玩家没有有效选择时使用的模型：

| 值         | 行为                                |
|-----------|-----------------------------------|
| `default` | 使用 ArcartX 默认玩家模型，界面显示内置的“默认外观”卡片 |
| 自定义外观 ID  | 使用 `models/*.yml` 中对应的模型，并对所有玩家开放 |

使用自定义默认外观时，该 ID 必须已经存在于模型目录。保留 ID `default` 不能写入模型配置。

## 界面与到期检查

| 配置                         | 说明              | 范围           |
|----------------------------|-----------------|--------------|
| `page-size`                | 每页显示的外观数        | `1`～`100`    |
| `expiration-check-seconds` | 检查在线玩家外观到期状态的间隔 | `5`～`3600` 秒 |

到期检查会让正在使用失效外观的玩家及时回到默认模型。

## 数据库

| 配置                            | 说明                        |
|-------------------------------|---------------------------|
| `type`                        | `sqlite` 或 `mysql`        |
| `sqlite-file`                 | SQLite 文件名                |
| `worker-threads`              | 数据库工作线程，范围 `1`～`16`       |
| `mysql.host`                  | MySQL 地址                  |
| `mysql.port`                  | 端口，范围 `1`～`65535`         |
| `mysql.database`              | 数据库名                      |
| `mysql.username`              | 用户名                       |
| `mysql.password`              | 密码                        |
| `mysql.parameters`            | JDBC 连接参数，不要在开头写 `?`      |
| `mysql.pool-size`             | 连接池大小，范围 `2`～`32`         |
| `mysql.connection-timeout-ms` | 连接超时，范围 `2000`～`60000` 毫秒 |

Appearance 会创建两个数据表：

| 表                   | 内容             |
|---------------------|----------------|
| `appearance_player` | 玩家当前选择的非默认外观   |
| `appearance_unlock` | 玩家解锁的外观与绝对到期时间 |



## 重新读取配置

执行 `/appearance reload` 后会重新读取：

- `config.yml`；
- `language.yml`；
- `models/` 下的所有模型；
- `ui/appearance.yml`。

`database.yml` 只在完整启动时生效。修改数据库类型、连接或工作线程后需要重启服务器。
