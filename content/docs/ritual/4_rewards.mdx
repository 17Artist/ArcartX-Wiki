# 奖励内容

每个日期和七日全勤奖励都可以分别设置邮件内容，并组合物品、货币和命令附件。

## 物品奖励

进入物品页面后，点击玩家背包中的物品即可复制一份奖励快照；点击上方已经添加的物品可以移除。

每份奖励最多保存 54 个物品附件。

## 货币奖励

输入格式：

```text
货币类型|数量|显示名称|图标路径
```

显示名称和图标路径可以留空：

```text
Vault|100|金币|
```

货币类型必须已经由 ArcartX 注册，编辑器会在保存前检查。每份奖励最多保存 32 个货币附件。

## 命令奖励

输入格式：

```text
执行方式|显示名称|图标路径|命令
```

执行方式可填写 `console`、`player`、`控制台` 或 `玩家`。命令开头不需要斜杠：

```text
console|会员体验|ritual/crown.png|lp user {player} parent addtemp vip 1d
```

使用 `player` 时，命令由领取邮件附件的玩家身份执行，受玩家权限限制。每份奖励最多保存 32 个命令附件。

## 邮件占位符

邮件标题、正文、发件人名称和命令支持：

| 占位符        | 内容                |
|------------|-------------------|
| `{player}` | 玩家当前名称            |
| `{uuid}`   | 玩家 UUID           |
| `{group}`  | 管理员设置的奖励组名称       |
| `{week}`   | 本周周一至周日日期范围       |
| `{date}`   | 当前奖励对应日期；全勤奖励使用周日 |
| `{day}`    | 周一至周日或“七日全勤”      |

发件人头像和非物品奖励图标使用客户端资源路径。留空时，货币和命令会分别使用 `ritual/icons/icon-coins.png` 与 `ritual/icons/icon-command.png`。
