# 管理命令与编辑器

## 命令

| 命令                            | 权限                    | 说明                     |
|-------------------------------|-----------------------|------------------------|
| `/ritual gui`                 | `ritual.admin.edit`   | 打开奖励组管理界面              |
| `/ritual edit <组ID>`          | `ritual.admin.edit`   | 直接打开指定奖励组              |
| `/ritual create <组ID> <管理名称>` | `ritual.admin.edit`   | 创建空奖励组                 |
| `/ritual retry <奖励记录ID>`      | `ritual.admin.retry`  | 重新启用已暂停的邮件投递           |
| `/ritual reload`              | `ritual.admin.reload` | 重载玩家提示、奖励组、当前周奖励和签到 UI |

数据库、时区、轮换起点和许可证变化后需要完整重启，不能通过 `/ritual reload` 生效。

`/ritual gui` 和 `/ritual edit` 只能由玩家执行；`create`、`retry` 和 `reload` 也可由控制台执行。管理权限默认仅向 OP 开放，`ritual.use` 默认向所有玩家开放。`/rit` 是 `/ritual` 的别名。

新建奖励组会立即参与轮换，但它的周一至周日和全勤奖励默认全部关闭。创建后应及时编辑并保存；如暂不准备启用整组，请在管理界面关闭“参与轮换”。

## 编辑奖励组

执行 `/ritual gui` 后：

1. 从列表中选择奖励组，或点击“创建奖励组”；
2. 创建时按照 `组ID|管理名称` 输入；
3. 在组编辑页选择周一至周日或“七日全勤”；
4. 设置奖励名称、介绍、启用状态、邮件发件人、标题、正文和领取期限；
5. 分别进入物品、货币或命令页面添加奖励；
6. 返回组编辑页并点击“保存整组修改”。

关闭界面或选择放弃会丢弃尚未保存的修改。点击“顺序前移”或“顺序后移”会先保存当前修改，再调整顺序；删除奖励组需要在聊天栏确认，确认后立即生效。聊天输入期间可输入“取消”返回；奖励介绍、发件人头像和邮件正文可输入“清空”移除内容。

奖励自动投递暂停时，Ritual 会在告警日志中写出 `记录 <ID>`。排查原因后，将这个 ID 填入 `/ritual retry <奖励记录ID>`，恢复该记录的自动发送。

## 修改玩家界面

授权通过后的首次业务启动会生成 `plugins/Ritual/ui/signin.yml`。常规启动不会覆盖已有文件。修改界面前先备份，保存后执行 `/ritual reload` 重新载入；这个命令也会重新读取 `language.yml` 和当前周奖励。
