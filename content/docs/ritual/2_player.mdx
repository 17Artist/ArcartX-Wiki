# 玩家签到

玩家执行以下命令打开签到界面：

```text
/ritual open
```

也可以使用简写 `/rit open`。所需权限为 `ritual.use`，默认向所有玩家开放。

## 签到规则

- 一个周期从周一 00:00 开始，到下周一 00:00 结束；
- 每天只能签到一次，错过的日期不能补签；
- 周一至周日分别使用独立奖励；
- 七天全部签到后，在周日领取全勤奖励；
- 周期时间以服务器 `timezone` 配置为准；
- 服务器停机不会暂停自然周，重新开服后会按实际日期恢复。


## 签到结果

| 情况      | 结果                   |
|---------|----------------------|
| 签到成功    | 当天出勤立即写入数据库，奖励随后进入邮箱 |
| 当日奖励关闭  | 仍记录出勤，但不创建奖励邮件       |
| 邮件暂时不可用 | 出勤不会丢失，奖励保留为待发送并自动重试 |
| 重复签到    | 不增加出勤，也不会重复生成邮件      |
| 全勤奖励    | 须在周日操作，并且本周七条出勤记录完整  |

## 界面状态

每日奖励可能显示：

| 状态   | 说明                 |
|------|--------------------|
| 可签到  | 今天尚未签到             |
| 已签到  | 出勤已记录，奖励已送达或该日奖励关闭 |
| 发放中  | 出勤已记录，邮件仍在处理       |
| 发放失败 | 自动投递已经暂停，需要管理员处理   |
| 已错过  | 日期已过且没有签到          |
| 未开放  | 日期尚未到              |

全勤奖励还可能显示“未达成”或“已关闭”。
