# 玩家签到

玩家执行以下命令打开当前签到界面：

```text
/advent open
```

也可以使用 `/adv open`。所需权限为 `advent.use`，默认向所有玩家开放。

## 新人七日签到

- 玩家首次在 Advent 建档的当天就是新人第 1 天；
- 只有七次领取发生在连续七个自然日，才可领取额外奖励；

## 回归七日签到

- 玩家连续离线满 `returning.inactive-days` 天后，下次进入服务器时开启；离线天数按每 24 小时累计；
- 开启当天是第 1 天，日奖励和连续奖励规则与新人签到相同；
- 活动只在 `returning.claim-window-days` 个自然日内可领取；
- 到期时刻为开始日期加窗口天数后的本地 00:00；
- 到期后仍持续离线时，下一轮资格从本轮到期时刻开始累计；
- 到期后若玩家先上线但尚未达到下一轮资格，离线时间会从这次上线重新累计。

## 界面状态

| 状态    | 含义                    |
|-------|-----------------------|
| 可领取   | 当前自然日可以领取下一份日奖励       |
| 已领取   | 该份奖励已发送，或该日奖励关闭但进度已记录 |
| 明日开放  | 今天已完成签到，等待下一个自然日      |
| 发放中   | 签到资格已保存，邮件仍在处理        |
| 待处理   | 自动投递已经暂停，需要管理员处理      |
| 已过期   | 回归活动已超过领取期限           |
| 未开放   | 尚未轮到该份奖励              |
| 未达成连签 | 七份日奖励已完成，但不符合连续七日条件   |
| 未启用   | 管理员关闭了额外奖励            |
