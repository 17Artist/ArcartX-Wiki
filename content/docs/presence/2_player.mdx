# 玩家使用

玩家使用以下命令打开在线奖励面板：

```text
/presence open
```

主命令也可以简写为 `/prs`，默认需要 `presence.use` 权限。

## 奖励状态

| 状态   | 含义              |
|------|-----------------|
| 未解锁  | 今日在线时长尚未达到要求    |
| 可领取  | 已达到要求，可以提交领取    |
| 发放中  | 领取资格已经记录，奖励正在投递 |
| 已领取  | 奖励邮件已经发放        |
| 暂未发放 | 自动投递已暂停，需要管理员处理 |

每天零点按 `config.yml` 中的 `timezone` 重置今日在线时长与可领取阶段。

## HUD

HUD 显示下一份尚未解锁的奖励、剩余时间和当前阶段进度。全部启用阶段达到要求后，显示“全部解锁”。

倒计时由客户端根据服务端发送的阶段时间计算，无需担心持续无脑发包。
