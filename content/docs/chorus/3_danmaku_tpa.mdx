# 弹幕与 TPA

## 弹幕

弹幕是内置且必须存在的 `GLOBAL` 频道。选择弹幕频道后，输入框会显示本次消耗和当前余额；输入内容并按 Enter 即可发送。

- 每条弹幕都会检查消息长度、Redact、发送频率和余额；
- 移动时间由 `danmaku.duration-millis` 控制；
- 字号来自玩家当前命中的弹幕格式，范围为 `12..72`；

管理员可使用 `/chorus danmaku give <玩家> <数量>` 发放发射器余额，玩家使用 `/chorus danmaku balance` 查询自己的发射器余额。

## TPA

玩家可通过以下命令或玩家操作菜单发起传送请求：

```text
/tpa send <玩家>
```

目标服已满、容量无法确认、目标换服或连接失败时，传送会被取消并给出提示。

跨服 TPA 要求代理和目标 Bukkit 节点都安装同一版本的 Chorus 组件，并保持 TPA 相关配置一致。
