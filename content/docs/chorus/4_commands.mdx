# 命令与权限

| 命令                                                   | 权限                       | 执行者    | 说明                                           |
|------------------------------------------------------|--------------------------|--------|----------------------------------------------|
| `/chorus reload`                                     | `chorus.admin.reload`    | 玩家或控制台 | 重新读取业务配置、卡片和 UI；数据库与授权连接设置需要重启               |
| `/chorus showitem`                                   | `chorus.showitem`        | 玩家     | 向当前频道的接收者展示主手物品                              |
| `/chorus raw <在线玩家或UUID或*> <内容>`                     | `chorus.admin.raw`       | 玩家或控制台 | 发送不经过频道格式的颜色文本；`*` 表示全部在线玩家，代理模式下包括同一代理的其他子服 |
| `/chorus card send <在线玩家或UUID> <卡片> [key=value ...]` | `chorus.admin.card`      | 玩家或控制台 | 向目标玩家发送已注册卡片；数据项使用 `key=value`               |
| `/chorus danmaku give <在线玩家> <数量>`                   | `chorus.admin.danmaku`   | 玩家或控制台 | 增加玩家的弹幕发射器余额，不能超过配置上限                        |
| `/chorus danmaku balance`                            | `chorus.danmaku.balance` | 玩家     | 查询自己的弹幕发射器余额                                 |
| `/tpa send <在线玩家>`                                   | `chorus.tpa`             | 玩家     | 发起 TPA 请求；玩家菜单中也有对应操作                        |

## 常用权限

| 权限                        | 作用                       |
|---------------------------|--------------------------|
| `chorus.chat.color`       | 允许消息正文中的颜色代码生效           |
| `chorus.channel.danmaku`  | 使用弹幕频道                   |
| `chorus.format.owner`     | 使用综合频道的 `owner` 特殊格式     |
| `chorus.danmaku.featured` | 使用弹幕频道的 `featured` 格式与字号 |


`/chorusui open <UUID>` 是点击聊天姓名时使用的内部入口。玩家无需手工执行，服主也无需将它作为管理命令开放。
