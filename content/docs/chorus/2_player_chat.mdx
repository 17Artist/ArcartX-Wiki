# 聊天与玩家互动

## 频道聊天

点击频道按钮可切换发送频道。频道切换成功后，服务端会同步当前频道和聊天过滤前缀：

- 综合频道默认不设置过滤前缀，因此会显示客户端已经收到的全部聊天；
- 队伍、公会等频道可以设置独立前缀，只显示对应内容；
- 客户端过滤只改变显示范围，玩家能否真正收到消息仍由频道权限和接收者解析器决定。

默认 `team` 频道只是接入示例，Chorus 本身不提供队伍系统。需要由组队、公会等外部插件在 Bukkit 节点注册对应频道和接收者解析器。

## 跨服频道

`LOCAL` 频道只在当前 Bukkit 子服发送。`GLOBAL` 频道在开启代理模式后会转发到代理(BC/VC)下的其他子服，每个目标子服再按本地同名频道、接收者解析器和接收权限筛选玩家。

要让队伍或公会频道跨服工作，需要同时满足：

1. 所有相关子服接入同一个代理(BC/VC)；
2. 子服中都存在同名频道；
3. 子服中都注册了同名接收者解析器；
4. 外部插件的成员数据在各节点可用；
5. 频道为 `GLOBAL`，玩家具有对应发送和接收权限。

## 玩家操作菜单与私聊

点击其他玩家消息中的发送者名称可打开玩家操作菜单。

选择“私聊”后，输入栏会显示目标玩家。输入内容并按 Enter 后，消息只进入私聊；点击目标标签可取消私聊并回到当前频道。

“屏蔽 / 解除私信”会持久化玩家的私聊屏蔽关系。被屏蔽的发送者只会收到失败提示。

## `@` 提示音

Chorus 会按完整玩家名边界、不区分大小写地识别 `@玩家名`，只向被提及玩家播放提示音。

以玩家名 `17Artist` 为例：

| 文本                        | 是否触发 | 原因              |
|---------------------------|-----:|-----------------|
| `@17Artist`               |    是 | 名称两侧均为边界        |
| `你好 @17Artist，我是18Artist` |    是 | `@` 前有空格，名称后有标点 |
| `你好@17Artist`             |    否 | `@` 前紧邻其他文字     |
| `@17Artist_2`             |    否 | 名称后仍是名称字符       |

## 手持物品展示

执行 `/chorus showitem` 可向当前频道展示主手物品：

- 主手为空时不会发送；
- 可以配置经济服务、展示价格和是否收费；
