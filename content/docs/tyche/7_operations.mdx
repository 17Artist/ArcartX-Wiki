# 交易核对与维护

## 查看待核对交易

扣款或发放途中异常、服务器在处理时关闭等情况可能留下待核对订单。该玩家的后续购买与刷新暂停，等待管理员确认。

使用 `/tyche inspect <player>` 查看订单 ID、商品名称或刷新操作、支付金额、币种与处理进度。商品名称和金额来自保存的订单，币种名称来自当前经济接口，取不到时显示接口 ID。


| 操作                                           | 适用条件与结果                             |
|----------------------------------------------|-------------------------------------|
| `/tyche resolve <player> <request> complete` | 已扣款且全部内容已发放，保存完成结果，计入订单所属日期的限购或刷新次数 |
| `/tyche resolve <player> <request> cancel`   | 确认交易未发生，或已人工退款并回收全部内容，结束订单          |

<Callout type="warn">
两种操作只登记核对结果，不执行扣款、发货、退款或物品回收，也不会撤销已执行的命令。结果不明确时保留待核对订单。
</Callout>
