# 仓库配置

## 主配置

`plugins/Storehouse/config.yml`：

```yaml
initial-warehouses: 1
max-warehouses: 10
remark-max-length: 12
save-interval-seconds: 30

unlock:
  currency: Vault
  base-price: 1000.0
  price-increment: 1000.0
  prices: {}
```

| 配置项                      | 说明                                                  |
|--------------------------|-----------------------------------------------------|
| `initial-warehouses`     | 新玩家首次使用时的仓库数量，至少 1，不能超过上限                           |
| `max-warehouses`         | 可解锁上限，范围 `1..100`；降低上限不会删除已解锁仓库                     |
| `remark-max-length`      | 备注上限，范围 `1..64` 个 Unicode 字符，默认 12                  |
| `save-interval-seconds`  | 打开期间的保存间隔，范围 `5..300` 秒，默认 30                       |
| `unlock.currency`        | ArcartX 已注册的货币提供者标识，区分大小写，例如 `Vault`、`PlayerPoints` |
| `unlock.base-price`      | 第一个额外仓库的费用                                          |
| `unlock.price-increment` | 后续每个仓库增加的费用                                         |
| `unlock.prices`          | 按仓库编号设置费用，优先于递增计算                                   |

切仓和关仓等操作会立即提交，不等待定期保存。降低备注上限不会截断已保存的备注。

## 解锁费用

没有单独设置费用时，按以下公式计算：

```text
base-price + max(0, 仓库编号 - initial-warehouses - 1) × price-increment
```

初始一个仓库、基础费用 1000、每次增加 1000 时，第 2、3 个仓库分别需要 1000、2000。

可以单独指定第 4 个仓库为 5000：

```yaml
unlock:
  currency: Vault
  base-price: 1000.0
  price-increment: 1000.0
  prices:
    4: 5000.0
```

费用可为零，每项不得超过 `1000000000`；使用 `PlayerPoints` 时必须为整数。货币显示名称由 ArcartX 货币提供器返回。

## 文件与生效方式

以下路径均位于 `plugins/Storehouse/`：

| 路径                                      | 用途                   | 生效方式                 |
|-----------------------------------------|----------------------|----------------------|
| `license.yml`                           | 许可证 ID 与密钥           | 重启                   |
| `config.yml`                            | 仓库、备注、保存周期与费用        | `/storehouse reload` |
| `language.yml`                          | 玩家提示                 | `/storehouse reload` |
| `database.yml`                          | 数据库设置                | 重启                   |
| `ui/main.yml`                           | ArcartX 界面           | `/storehouse reload` |
| `storehouse.db`                         | SQLite 数据库           | 插件维护                 |
| `storehouse.db-wal`、`storehouse.db-shm` | SQLite 关联文件          | 数据库维护                |
| `.sqlite.lock`                          | 防止多个实例同时使用 SQLite 目录 | 插件维护，进程退出后释放占用       |
