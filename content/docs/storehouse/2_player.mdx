# 玩家使用

执行 `/storehouse open` 打开第一个仓库，也可以使用别名 `/sh open`。打开已解锁的指定仓库：

```text
/storehouse open 3
```

## 存取物品

界面左侧展示当前仓库与玩家背包。物品操作遵循原版容器规则，支持左右键、Shift、拖拽与快捷栏交换。

打开仓库时不能向地面丢弃物品，创造模式中键复制也会被阻止。需要丢弃物品时先关闭仓库。

关闭后，鼠标上的物品按原版流程返还；背包已满时遵循原版落地行为。

## 切换仓库

右侧目录每页显示五个仓库。翻页只改变目录，选择仓库或输入编号并打开后，才会切换当前仓库。

切仓和解锁前，先放下鼠标上的物品。操作需要先保存当前内容。

## 修改备注

打开备注弹窗，输入名称并保存。提交空白文字可以清除备注。

目录会缩短显示较长备注，编辑时仍使用完整内容。可输入的字符数由服主配置，默认 12 个 Unicode 字符。

## 解锁仓库

点击解锁按钮，确认下一个仓库的费用与货币。仓库按编号顺序解锁，余额不足时无法完成。

若确认期间服主调整了数量、费用或货币，请重新确认最新报价。如果提示“上次解锁需要管理员确认”，请联系管理员核对扣费记录。

## 保存与切服

打开期间按服主设置的间隔保存，定期保存时可以继续操作。切仓、修改备注、解锁、关仓、退出、切服和正常停服时，也会提交当前仓库内容。

跨服时自动关闭仓库，玩家可以正常进入目标服。如果源服尚未完成保存，目标服会暂时拒绝打开同一玩家的仓库，稍后重试即可。


## 特别注意
崩服、断电或长时间无法写入数据库时，最近一次成功保存后的变化可能回退。发现物品异常时，请保留现状并联系管理员核对。
