# 配置文件

## `config.yml`

```yaml
tracking:
  max-tracked: 3

quests:
  page-size: 12

waypoint:
  server-type: "open-world"
  enabled: true
  default-style: "default"
```

| 配置                       |          默认值 | 说明                                 |
|--------------------------|-------------:|------------------------------------|
| `tracking.max-tracked`   |          `3` | 每名玩家最多追踪的目标数，范围 `1`～`16`           |
| `quests.page-size`       |         `12` | 每页最多下发的任务摘要，范围 `1`～`50`            |
| `waypoint.server-type`   | `open-world` | 当前子服的类型，用于任务路标白名单                  |
| `waypoint.enabled`       |       `true` | 是否允许 ChemdahView 创建任务路标            |
| `waypoint.default-style` |    `default` | 目标未指定 `style` 时使用的 ArcartX 路标样式 ID |

界面通讯页码从 `0` 开始，玩家看到的页码通常从 `1` 开始。

`waypoint.server-type` 不是 Bukkit 世界名。多子服环境可以分别使用 `lobby`、`open-world`、
`dungeon` 等稳定标识，再由任务目标的 `worlds` 决定允许显示路标的世界。默认样式需要在
当前 ArcartX 配置中存在。

## 语言文件

`language.yml` 管理：

- 命令反馈；
- “全部”“已完成”等特殊分类名称；
- 已完成目标无法恢复标题时的文字；
- 任务面板和对话框的错误提示。

语言文本支持 `&` 颜色代码。任务标题、任务说明和目标文字不在此文件中，应修改 Chemdah
任务配置。
