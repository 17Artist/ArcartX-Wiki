# 配置文件

ChemdahView 的主配置位于 `plugins/ChemdahView/config.yml`：

```yaml
server:
  type: "open-world"

tracking:
  max-tracked: 3
  player-data-key: "chemdahview.tracked.v1"

ui:
  quest-page-size: 12

waypoint:
  enabled: true
  default-style: "default"

security:
  max-ui-field-length: 256
  max-ui-packet-fields: 8
  max-response-rewards: 32
  max-response-tasks: 64
  max-requests-per-second: 20
```

## 服务器与追踪

| 配置                         |                      默认值 | 说明                       |
|----------------------------|-------------------------:|--------------------------|
| `server.type`              |             `open-world` | 当前子服的类型，用于任务路标白名单        |
| `tracking.max-tracked`     |                      `3` | 每名玩家最多追踪的目标数，范围 `1`～`16` |
| `tracking.player-data-key` | `chemdahview.tracked.v1` | 追踪列表在 Chemdah 玩家数据中的键    |

`server.type` 不是 Bukkit 世界名。多子服环境可以分别使用 `lobby`、`open-world`、`dungeon` 等稳定标识，再由任务目标决定允许在哪类服务器显示路标。

<Callout type="warn">
修改 `tracking.player-data-key` 不会迁移旧数据。
</Callout>

## 任务面板

| 配置                   |  默认值 | 说明                      |
|----------------------|-----:|-------------------------|
| `ui.quest-page-size` | `12` | 每页最多下发的任务摘要，范围 `1`～`50` |

界面协议页码从 `0` 开始，玩家看到的页码通常从 `1` 开始。

## 路标

| 配置                       | 默认值       | 说明                                 |
|--------------------------|-----------|------------------------------------|
| `waypoint.enabled`       | `true`    | 是否允许 ChemdahView 创建任务路标            |
| `waypoint.default-style` | `default` | 目标未指定 `style` 时使用的 ArcartX 路标样式 ID |

默认样式需要在当前 ArcartX 配置中存在。单个目标还需要在 `arcartx-waypoint` 中声明服务器类型、世界和位置。

## 安全与响应限制

| 配置                                 |   默认值 |          范围 | 说明                            |
|------------------------------------|------:|------------:|-------------------------------|
| `security.max-ui-field-length`     | `256` | `32`～`4096` | 客户端单个字段的最大长度                  |
| `security.max-ui-packet-fields`    |   `8` |    `2`～`32` | 单次 UI 请求最多字段数                 |
| `security.max-response-rewards`    |  `32` |   `0`～`128` | 单个任务或目标最多缓存的奖励数，`0` 表示不提供奖励预览 |
| `security.max-response-tasks`      |  `64` |   `1`～`256` | 单个任务详情最多下发的目标数                |
| `security.max-requests-per-second` |  `20` |   `2`～`100` | 单名玩家每秒最多处理的任务面板动作             |

一般保持默认值即可。超出范围的数值会自动限制到最近边界。

## 语言文件

`language.yml` 管理：

- 命令反馈；
- “全部”“已完成”等特殊分类名称；
- 已完成目标无法恢复标题时的文字；
- 任务面板和对话框的错误提示。

语言文本支持 `&` 颜色代码和 `{action}` 等命名占位符。任务标题、任务说明和目标文字不在此文件中，应修改 Chemdah 任务配置。
