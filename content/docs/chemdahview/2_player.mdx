# 玩家使用

玩家可以执行以下命令打开任务面板：

```text
/chemdahview open
```

简写为 `/cv open`。如果 Chemdah 玩家资料仍在加载，稍等片刻后重新打开即可。

## 浏览任务

任务面板会显示任务分类、当前页任务和选中任务的详细内容。玩家点击任务后可以查看：

- 任务说明与所属分类；
- 各目标的标题、说明、状态和原生进度；
- 当前是否正在追踪目标；
- 任务与目标的奖励预览；
- 当前路标是否可用。

“全部”只显示正在进行的任务；“已完成”显示 Chemdah 已经记录的完成历史。普通分类来自任务的第一个 `meta.type`。

<Callout type="info">
奖励信息只用于预览。实际仍由 Chemdah 发放。
</Callout>

## 追踪目标

ChemdahView 追踪的是具体的“任务 ID + 目标 ID”，不是整项大任务。玩家可以在任务详情中：

- 追踪一个仍可执行的目标；
- 取消单个目标的追踪；
- 清空全部追踪目标。

已经完成、尚未解锁或不属于当前活动任务的目标不能加入追踪。达到服主设置的上限后，需要先取消一个目标。

追踪 HUD 会在目标进度、任务状态、世界或追踪列表发生变化时自动更新。

## 任务路标

路标只会为已经追踪的目标显示，并且需要同时满足：

1. 已经开启路标功能；
2. 任务目标声明了 `arcartx-waypoint`；
3. 当前服务器类型在目标白名单中；
4. 玩家所在世界在目标白名单中；
5. 路标位置与玩家处于同一世界；
6. ArcartX 客户端资源已经就绪。

玩家切换到不允许的世界、取消追踪或完成目标后，对应路标会被移除。

## Chemdah 对话

使用 `arcartx` 主题的 Chemdah 对话会打开 ChemdahView 对话框。


## 常见问题

### 任务没有出现在“已完成”

Chemdah 必须记录任务完成状态。完成历史只会出现在“已完成”分类。

### 路标没有显示

先确认目标已经追踪，再检查全局路标开关、服务器类型、世界白名单、路标样式和位置格式。

### 奖励显示了但没有发放

奖励预览与奖励发放是两件事。需要 Chemdah agent 中配置真实奖励。
