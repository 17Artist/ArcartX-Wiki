# 命令与管理

ChemdahView 的主命令为 `/chemdahview`，简写为 `/cv`。

## 命令

| 命令                    | 发送者 | 权限                         | 用途                           |
|-----------------------|-----|----------------------------|------------------------------|
| `/chemdahview open`   | 玩家  | 无额外权限                      | 打开自己的任务面板                    |
| `/chemdahview reload` | OP  | `chemdahview.admin.reload` | 重新读取配置、语言、任务界面与 Chemdah 任务模板 |

`reload` 同时要求发送者为 OP 并拥有对应权限。

## 重载内容

执行：

```text
/chemdahview reload
```

会重新读取：

- `config.yml` 与 `language.yml`；
- `ui/quests.yml`、`ui/tracker.yml`、`ui/conversation.yml` 和 `ui/interaction.yml`；
- Chemdah 任务模板中的展示、奖励与路标配置。

配置读取失败时，插件会继续使用重载前的有效设置。四份 UI 会先全部解析并检查必要根节点，
只有全部有效才会一起替换；任意一份 YAML 损坏时，已有 UI 注册和 UIHandler 回调继续使用，
不会进入部分新、部分旧的状态。许可证只在完整启动时读取。


## 排查顺序

| 问题            | 优先检查                                                                        |
|---------------|-----------------------------------------------------------------------------|
| 插件启动后禁用       | `license.yml` 是否填写了 ChemdahView 的有效授权                                       |
| 任务面板无法打开      | Chemdah 玩家资料是否加载完成，任务界面是否注册成功                                               |
| 修改 UI 后无变化    | 是否编辑数据目录文件，YAML 是否有效，是否执行插件重载                                               |
| 已完成任务不显示      | Chemdah 是否启用了完成记录，客户端是否选择“已完成”分类                                            |
| 路标不显示         | 追踪状态、全局开关、服务器类型、世界、样式和位置                                                    |
| 奖励没有显示        | `arcartx-view` 所在层级、ItemProvider 标识与物品 ID                                   |
| 附近 NPC HUD 为空 | Adyeshach 是否加载、对话 NPC 绑定、范围、高度差、可见性与 condition                              |
| 交互键无响应        | `conversation-interaction.default-key`、客户端个人绑定、当前高亮项，以及 ArcartX 重载后按键是否重新同步 |
