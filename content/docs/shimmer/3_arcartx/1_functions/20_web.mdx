## `Web.open(url){:Shimmer}`
- 在默认浏览器中打开指定URL

<Callout type="info">
- **参数**：
  - `url`: 字符串类型(网页地址)
- **调用示例**
```Shimmer
Web.open("https://example.com")
```
</Callout>

<Callout type="warn">
注意事项：
- URL必须以"https://"或"http://"开头
- 不符合要求的URL将被忽略且不会打开
- 该功能会调用系统默认浏览器打开链接
</Callout>
