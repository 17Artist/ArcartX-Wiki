<Callout type="error">
    自 1.21.8 版本起，由于 Mojang 对 Shader 系统进行了大规模重构，ArcartX 已移除对 Shader 的支持。以下 API 仅适用于 1.21.8 之前的版本。
</Callout>

## `Shader.start(shaderName){:aria}`
- 启动指定的着色器效果

<Callout type="info">
- **参数**：
  - `shaderName`: 字符串类型(着色器名称)
- **调用示例**
```aria
Shader.start("blur")
```
</Callout>

## `Shader.update(key, value){:aria}`
- 更新指定着色器的参数值

<Callout type="info">
- **参数**：
  - `key`: 键名
  - `value`: 值
- **调用示例**
```aria
Shader.update("blur", 0.5)
```
</Callout>

## `Shader.close(){:aria}`
- 关闭当前运行的着色器效果

<Callout type="info">
- **调用示例**
```aria
Shader.close()
```
</Callout>

<Callout type="warn">
注意事项：
- 所有着色器操作都在游戏主线程同步执行
- 确保在使用前正确加载着色器资源
- 过度使用复杂的着色器效果可能影响游戏性能
</Callout>
