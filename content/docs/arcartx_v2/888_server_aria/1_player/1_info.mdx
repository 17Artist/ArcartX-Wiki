- 以下函数的目标对象为**玩家**（`Player`），仅在目标为玩家时可用。

## `getLevel(){:aria}`
- 获取玩家当前经验等级
<Callout type="info">
    - **参数**：无
    - **返回值**：整数类型
    - **调用示例**
    ```aria
    玩家对象.getLevel()
    ```
</Callout>

## `getExp(){:aria}`
- 获取玩家当前等级的经验进度，范围为 `0.0` 到 `1.0`
<Callout type="info">
    - **参数**：无
    - **返回值**：单精度浮点数类型
    - **调用示例**
    ```aria
    玩家对象.getExp()
    ```
</Callout>

## `hasPermission(permission){:aria}`
- 判断玩家是否拥有指定权限
<Callout type="info">
    - **参数**：`permission` — 字符串类型，权限节点；参数缺失、多余或为空时返回 `false`
    - **返回值**：布尔类型
    - **调用示例**
    ```aria
    玩家对象.hasPermission("arcartx.admin")
    ```
</Callout>

## `getPlaceholder(placeholder){:aria}`
- 以该玩家为对象解析 PlaceholderAPI 变量，并返回解析后的字符串
<Callout type="info">
    - **参数**：`placeholder` — 字符串类型，待解析的 PAPI 变量文本（如 `%player_name%`）
    - **返回值**：字符串类型（解析结果；参数数量不为 1 时返回空字符串）
    - **调用示例**
    ```aria
    玩家对象.getPlaceholder("%player_name%")
    ```
</Callout>
