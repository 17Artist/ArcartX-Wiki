- 以下函数的目标对象为**生物实体**（`LivingEntity`）。玩家也是生物实体，因此这些函数对玩家目标同样有效。

## `isInWater(){:aria}`
- 判断实体是否在水中
<Callout type="info">
    - **参数**：无
    - **返回值**：布尔类型
    - **调用示例**
    ```aria
    实体对象.isInWater()
    ```
</Callout>
