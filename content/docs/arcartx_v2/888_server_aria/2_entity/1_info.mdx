- 以下函数的目标对象为**生物实体**（`LivingEntity`）。玩家也是生物实体，因此这些函数对玩家目标同样有效。

## `getName(){:aria}`
- 获取实体名称
<Callout type="info">
    - **参数**：无
    - **返回值**：字符串类型
    - **调用示例**
    ```aria
    实体对象.getName()
    ```
</Callout>
