## ArcartXEntity

- `ArcartXEntity` 是ArcartX对Bukkit实体的包装对象，提供了模型、动画、发光、音效等功能的控制接口。
- 通过 `ArcartXEntityManager.getOrCreateEntity(entity)` 获取。
- `ArcartXPlayer` 继承自此类，玩家对象拥有本页所有方法以及更多扩展功能。
- 本类所有涉及客户端显示的方法均为**范围广播**模式——会向所有能看到该实体的玩家发送数据包。

## 公开属性

### `entity`
- 该对象所包装的 Bukkit 实体。
- 在 Java 中通过 `getEntity()` 访问。

<Callout type="info">
- **类型**：`Entity` — 被包装的 Bukkit 实体
- **调用示例**
```java
Entity entity = axEntity.getEntity();
```
</Callout>

## 生命周期

### `isExpired(){:java}`
- 判断该实体是否已失效（即对应的 Bukkit 实体不再有效）

<Callout type="info">
- **参数**：无
- **返回值**：`boolean` — 实体失效返回 true
- **调用示例**
```java
boolean expired = axEntity.isExpired();
```
</Callout>

## 模型管理

### `setModel(modelID, scale){:java}`
- 为实体设置模型

<Callout type="info">
- **参数**：
    - `modelID`: String — 模型ID
    - `scale`: double — 模型缩放比例
- **返回值**：无
- **调用示例**
```java
axEntity.setModel("my_model", 1.0);
```
</Callout>

### `setModel(modelID, scale, reset){:java}`
- 为实体设置模型，可选择是否重置动画状态

<Callout type="info">
- **参数**：
    - `modelID`: String — 模型ID
    - `scale`: double — 模型缩放比例
    - `reset`: boolean — 是否重置动画状态
- **返回值**：无
- **调用示例**
```java
axEntity.setModel("my_model", 1.5, true);
```
</Callout>

### `removeModel(){:java}`
- 移除实体的模型

<Callout type="info">
- **参数**：无
- **返回值**：无
- **调用示例**
```java
axEntity.removeModel();
```
</Callout>

## 碰撞与体积

### `setSize(width, height){:java}`
- 设置实体的碰撞体积，同时会同步到客户端显示

<Callout type="info">
- **参数**：
    - `width`: double — 碰撞箱宽度
    - `height`: double — 碰撞箱高度
- **返回值**：无
- **调用示例**
```java
axEntity.setSize(0.6, 1.8);
```
</Callout>

<Callout type="warn">
此方法会在主线程执行，如果你在异步线程调用，它会自动切换到主线程。
</Callout>

### `setHideHitBox(hide){:java}`
- 设置是否隐藏实体的碰撞箱显示

<Callout type="info">
- **参数**：`hide`: boolean — 是否隐藏
- **返回值**：无
- **调用示例**
```java
axEntity.setHideHitBox(true);
```
</Callout>

<Callout type="info">
- **参数**：

- 设置实体模型的默认动画状态

<Callout type="info">
- **参数**：
    - `state`: String — 状态名称
    - `name`: String — 动画名称
- **返回值**：无
- **调用示例**
```java
axEntity.setDefaultState("idle", "idle_animation");
```
</Callout>

### `playAnimation(animation, speed, transitionTime, keepTime){:java}`
- 为实体播放一次动画

<Callout type="info">
- **参数**：
    - `animation`: String — 动画名称
    - `speed`: double — 播放速度
    - `transitionTime`: int — 过渡时间（毫秒）
    - `keepTime`: long — 持续时间（毫秒），-1为播放完整动画
- **返回值**：无
- **调用示例**
```java
axEntity.playAnimation("attack", 1.0, 5, -1);
```
</Callout>

## 音效

### `playSound(resourcePath, soundCategory, distOrRoll, pitch, keepTime){:java}`
- 为实体播放音效，音效会跟随实体移动，向所有能看到该实体的玩家广播

<Callout type="info">
- **参数**：
    - `resourcePath`: String — 音效资源路径
    - `soundCategory`: String — 音效类别（如 `master`、`music`）
    - `distOrRoll`: int — 传播距离/衰减
    - `pitch`: double — 音调
    - `keepTime`: int — 持续时间（毫秒）
- **返回值**：无
- **调用示例**
```java
axEntity.playSound("sounds/hit.ogg", "master", 16, 1.0, 3000);
```
</Callout>

## 伤害显示

### `broadcastDamageDisplay(damageDisplayConfigId, damage){:java}`
- 在实体位置广播伤害数字，所有能看到该实体的玩家都会看到

<Callout type="info">
- **参数**：
    - `damageDisplayConfigId`: String — 伤害显示配置ID
    - `damage`: double — 伤害数值
- **返回值**：无
- **调用示例**
```java
axEntity.broadcastDamageDisplay("default", 100.0);
```
</Callout>

<Callout type="warn">
此方法是**范围广播**模式，会向所有能看到该实体的玩家发送伤害数字。如果你只想让特定玩家看到伤害数字，请使用 `sendDamageDisplayToPlayers` 或 `ArcartXPlayer.addDamageDisplay`。
</Callout>

### `sendDamageDisplayToPlayers(damageDisplayConfigId, damage, players){:java}`
- 在实体位置显示伤害数字，仅指定列表中的玩家可见

<Callout type="info">
- **参数**：
    - `damageDisplayConfigId`: String — 伤害显示配置ID
    - `damage`: double — 伤害数值
    - `players`: List&lt;Player&gt; — 可见玩家列表
- **返回值**：无
- **调用示例**
```java
List<Player> viewers = Arrays.asList(player1, player2);
axEntity.sendDamageDisplayToPlayers("default", 50.0, viewers);
```
</Callout>

## 状态同步

### `startSeenBy(target){:java}`
- 向指定玩家同步该实体当前的全部显示状态（模型、体积、隐藏骨骼、默认动画状态、发光颜色与开关、名称显示、碰撞箱隐藏等）。通常在实体开始被某玩家看到时调用

<Callout type="info">
- **参数**：`target`: Player — 目标玩家
- **返回值**：无
- **调用示例**
```java
axEntity.startSeenBy(player);
```
</Callout>

### `syncSize(){:java}`
- 校验并同步实体的碰撞体积。当已设置过体积且服务端实体当前体积与设定值不一致时，重新应用设定的宽高

<Callout type="info">
- **参数**：无
- **返回值**：无
- **调用示例**
```java
axEntity.syncSize();
```
</Callout>
