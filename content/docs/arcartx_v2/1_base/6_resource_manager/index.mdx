## 它是什么

资源同步后端是一个**独立部署的资源更新服务**，与游戏端的 **ArcartX 插件**配合，实现资源文件的上传、托管与按需下发。整条链路是这样运转的：

1. 你在后端的管理后台上传资源包（`.zip`）。
2. 后端为每个文件计算 CRC64 校验值，对外提供「文件清单」与「签名下载链接」两个接口。
3. 游戏端 ArcartX 插件用 API 密钥拉取清单、比对本地文件，再通过签名链接下载有变更的资源。

<Callout type="warn">
**关于资源同步的重要警告**

启用资源同步后，客户端 `ArcartX/resource` 目录下**所有 `.zip` 文件**都会与后端保持一致——也就是说，**后端没有的资源包，会在同步时从客户端被移除**。

请务必先把正在开发的资源包上传到后端，避免因同步导致资源包被删、开发进度丢失。
</Callout>
