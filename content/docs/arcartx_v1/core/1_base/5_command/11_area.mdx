## 区域指令

- 用于获取区域编辑工具。

### `arcartx area tool`

- 获取区域编辑工具到背包中

| 属性  | 值                            |
|-----|------------------------------|
| 用法  | `arcartx area tool`          |
| 权限  | `arcartx.command.admin.area` |
| 执行者 | 仅玩家                          |

- 获取到的工具是一根附魔木棍，使用方式如下：
  - 左键/右键 — 选择区域两端对角
  - ALT + 右键 — 删除区域
  - ALT + 左键 — 取消选择
  - Shift + 右键 — 创建区域
  - Shift + 左键 — 编辑所在区域优先级
