<Callout type="info">
Spring是一个模拟真实弹簧物理特性的插值对象。通过调节张力和阻尼系数，可以创建各种不同特性的弹簧动画效果。
</Callout>

## 实例化方式

### `Spring`含参实例化
<Callout type="info">
- **描述**：创建一个弹簧插值实例。
- **参数**：
  - `start`：数值类型，起始值
  - `end`：数值类型，结束值
  - `tension`：数值类型，弹簧张力系数
  - `damping`：数值类型，阻尼系数
  - `transferTime`：长整型，过渡时间（毫秒）
- **调用示例**：
```Shimmer
Spring(0, 100, 170.0, 26.0, 1000) // 1秒内从0到100，使用默认弹性参数
```
</Callout>

### 默认参数
<Callout type="info">
当不提供完整参数时，使用以下默认值：
- **张力系数**: 170.0
- **阻尼系数**: 26.0
- **过渡时间**: 1000毫秒
</Callout>

### 参数说明
<Callout type="info">
- **张力系数(tension)**：控制弹簧的劲度，值越大震荡频率越高
- **阻尼系数(damping)**：控制震荡的衰减速度，值越大震荡衰减越快
</Callout>

## 函数

### `get(){:Shimmer}`
- 获取当前插值计算的结果

<Callout type="info">
- **参数**：无
- **返回值**：数值类型
- **说明**：根据当前时间计算弹簧物理模型的插值结果
- **调用示例**：
```Shimmer
Spring(0, 100, 170.0, 26.0, 1000).get()
```
</Callout>

### `reset(){:Shimmer}`
- 重置插值器状态

<Callout type="info">
- **参数**：无
- **返回值**：无
- **说明**：重置计时器并清除反向状态，重新开始动画
- **调用示例**：
```Shimmer
Spring(0, 100, 170.0, 26.0, 1000).reset()
```
</Callout>

### `reverse(){:Shimmer}`
- 反转动画方向

<Callout type="info">
- **参数**：无
- **返回值**：无
- **说明**：将动画方向反转，从当前位置开始向起始值过渡
- **调用示例**：
```Shimmer
Spring(0, 100, 170.0, 26.0, 1000).reverse()
```
</Callout>

## 类型转换

Spring对象支持以下类型转换：
- **数值**：返回当前插值计算的结果
- **布尔值**：当前值大于0时返回true，否则返回false
- **字符串**：返回当前插值计算结果的字符串表示

<Callout type="info">
Spring对象支持数学运算，可以直接参与计算表达式。
</Callout>
