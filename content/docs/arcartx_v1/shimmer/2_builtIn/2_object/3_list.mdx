## `add(element){:Shimmer}`
- 向目标列表中添加元素

<Callout type="info">
- **参数**：`element`：对象类型
- **返回值**：无
- **调用示例**
```Shimmer
[].add('元素')
```
- **示例返回值**
```Shimmer
none
```
</Callout>

## `add(index, element){:Shimmer}`
- 在目标列表的指定索引位置添加元素

<Callout type="info">
- **参数**：`index`：整数类型，`element`：对象类型
- **返回值**：无
- **调用示例**
```Shimmer
[].add(1, '元素')
```
- **示例返回值**
```Shimmer
none
```
</Callout>

## `get(index){:Shimmer}`
- 获取目标列表中指定索引位置的元素

<Callout type="info">
- **参数**：`index`：整数类型
- **返回值**：对象类型
- **调用示例**
```Shimmer
['abc','元素'].get(1)
```
- **示例返回值**
```Shimmer
'元素'
```
</Callout>

## `removeIndex(index){:Shimmer}`
- 移除目标列表中指定索引位置的元素，并返回被移除的元素

<Callout type="info">
- **参数**：`index`：整数类型
- **返回值**：对象类型
- **调用示例**
```Shimmer
['abc','元素'].removeIndex(1)
```
- **示例返回值**
```Shimmer
'元素'
```
</Callout>

## `containsAll(collection){:Shimmer}`
- 判断目标列表是否包含指定集合中的所有元素

<Callout type="info">
- **参数**：`collection`：集合类型
- **返回值**：布尔类型
- **调用示例**
```Shimmer
['abc','元素1','元素2'].containsAll(['元素1', '元素2'])
```
- **示例返回值**
```Shimmer
true
```
</Callout>

## `indexOf(element){:Shimmer}`
- 获取目标列表中指定元素首次出现的索引位置

<Callout type="info">
- **参数**：`element`：对象类型
- **返回值**：整数类型
- **调用示例**
```Shimmer
['abc','元素'].indexOf('元素')
```
- **示例返回值**
```Shimmer
1
```
</Callout>

## `lastIndexOf(element){:Shimmer}`
- 获取目标列表中指定元素最后一次出现的索引位置

<Callout type="info">
- **参数**：`element`：对象类型
- **返回值**：整数类型
- **调用示例**
```Shimmer
['abc','元素','元素','元素'].lastIndexOf('元素')
```
- **示例返回值**
```Shimmer
3
```
</Callout>

## `set(index, element){:Shimmer}`
- 设置目标列表中指定索引位置的元素，并返回该位置原来的元素

<Callout type="info">
- **参数**：`index`：整数类型，`element`：对象类型
- **返回值**：对象类型
- **调用示例**
```Shimmer
['abc','元素'].set(1, '新元素')
```
- **示例返回值**
```Shimmer
'元素'
```
</Callout>

## `subList(fromIndex, toIndex){:Shimmer}`
- 获取目标列表中从指定开始索引到结束索引（不包含结束索引对应元素）的子列表

<Callout type="info">
- **参数**：`fromIndex`：整数类型，`toIndex`：整数类型
- **返回值**：列表类型
- **调用示例**
```Shimmer
['abc','元素','元素1','元素2'].subList(1, 3)
```
- **示例返回值**
```Shimmer
['元素', '元素1']
```
</Callout>

## `size(){:Shimmer}`
- 获取目标列表中元素的数量，即列表的大小

<Callout type="info">
- **参数**：无
- **返回值**：整数类型
- **调用示例**
```Shimmer
['元素', '元素1'].size()
```
- **示例返回值**
```Shimmer
2
```
</Callout>

## `isEmpty(){:Shimmer}`
- 判断目标列表是否为空，即不包含任何元素

<Callout type="info">
- **参数**：无
- **返回值**：布尔类型
- **调用示例**
```Shimmer
['元素', '元素1'].isEmpty()
```
- **示例返回值**
```Shimmer
false
```
</Callout>

## `clear(){:Shimmer}`
- 清空目标列表，移除其中所有的元素

<Callout type="info">
- **参数**：无
- **返回值**：无
- **调用示例**
```Shimmer
['元素', '元素1'].clear()
```
- **示例返回值**
```Shimmer
none
```
</Callout>

## `remove(element){:Shimmer}`
- 移除目标列表中首次出现的指定元素，并返回是否移除成功的布尔值

<Callout type="info">
- **参数**：`element`：对象类型
- **返回值**：布尔类型
- **调用示例**
```Shimmer
['元素', '元素1'].remove('元素')
```
- **示例返回值**
```Shimmer
true
```
</Callout>

## `contains(element){:Shimmer}`
- 判断目标列表是否包含指定元素

<Callout type="info">
- **参数**：`element`：对象类型
- **返回值**：布尔类型
- **调用示例**
```Shimmer
['元素', '元素1'].contains('元素')
```
- **示例返回值**
```Shimmer
true
```
</Callout>

## `addAll(collection){:Shimmer}`
- 将指定集合中的所有元素添加到目标列表末尾，并返回是否添加成功的布尔值

<Callout type="info">
- **参数**：`collection`：集合类型
- **返回值**：布尔类型
- **调用示例**
```Shimmer
['元素', '元素1'].addAll(['元素1', '元素2'])
```
- **示例返回值**
```Shimmer
true
```
</Callout>

## `removeAll(collection){:Shimmer}`
- 从目标列表中移除指定集合中包含的所有元素，并返回是否移除成功的布尔值

<Callout type="info">
- **参数**：`collection`：集合类型
- **返回值**：布尔类型
- **调用示例**
```Shimmer
['元素1', '元素2'].removeAll(['元素1', '元素2'])
```
- **示例返回值**
```Shimmer
true
```
</Callout>

## `retainAll(collection){:Shimmer}`
- 仅保留目标列表中与指定集合中元素相同的元素，移除其他元素，并返回是否操作成功的布尔值

<Callout type="info">
- **参数**：`collection`：集合类型
- **返回值**：布尔类型
- **调用示例**
```Shimmer
['元素1', '元素2','元素3'].retainAll(['元素1', '元素2'])
```
- **示例返回值**
```Shimmer
true
```
</Callout>
