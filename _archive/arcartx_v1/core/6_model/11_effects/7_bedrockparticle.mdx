## 基岩粒子效果

基岩粒子效果可以在模型的定位器（Locator）位置播放基岩版粒子。粒子会跟随定位器的位置和旋转，实现精确的特效绑定。

## 使用方式

在动画的粒子效果帧中添加粒子命令：

<img src="/model/effects/bedrock-particle.png" alt="配置粒子效果帧"/>

```
arcartx:particle{id=模型id;remove=true}
```

| 参数     |   类型    | 默认值  | 说明                               |
|:-------|:-------:|:----:|:---------------------------------|
| id     | string  |  必填  | 粒子 ID                            |
| remove | boolean | true | 动作完成后是否立刻移除发射器（不要给循环播放的粒子打开这个选项） |

定位器本身支持旋转，粒子会继承定位器的旋转角度。结合 `yaw` 和 `pitch` 附加值，可以精确控制粒子的发射方向。
