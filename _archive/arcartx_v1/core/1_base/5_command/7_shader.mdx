## 着色器指令

<Callout type="error">
    自 1.21.8 版本起，由于 Mojang 对 Shader 系统进行了大规模重构，ArcartX 已移除对 Shader 的支持。以下指令仅适用于 1.21.8 之前的版本。
</Callout>

- 用于为玩家开启或关闭后处理着色器效果。

### `arcartx shader start`

- 为玩家开启一个着色器

| 属性  | 值                                            |
|-----|----------------------------------------------|
| 用法  | `arcartx shader start <player> <shaderName>` |
| 权限  | `arcartx.command.admin.shader`               |
| 执行者 | 仅OP                                          |

- `player`：目标玩家名
- `shaderName`：着色器名称

### `arcartx shader stop`

- 为玩家关闭着色器

| 属性  | 值                              |
|-----|--------------------------------|
| 用法  | `arcartx shader stop <player>` |
| 权限  | `arcartx.command.admin.shader` |
| 执行者 | 仅OP                            |

- `player`：目标玩家名
