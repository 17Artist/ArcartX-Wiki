## 资源校验指令

- 用于更新客户端拓展的CRC64校验列表，确保客户端资源完整性。

### `arcartx crc64 update`

- 从当前玩家客户端获取CRC64校验列表并更新到服务端配置

| 属性  | 值                             |
|-----|-------------------------------|
| 用法  | `arcartx crc64 update`        |
| 权限  | `arcartx.command.admin.crc64` |
| 执行者 | 仅玩家                           |

- 执行后会将你客户端的CRC64校验值同步到服务端配置文件中。
